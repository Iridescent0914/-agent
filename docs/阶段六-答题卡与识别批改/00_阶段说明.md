# 阶段六：答题卡与识别批改

本阶段承接现有组卷、发布、打印和批改流程，集中处理学生答题卡的排版、采集、识别及答案比对。这里的“阶段六”是新的需求阶段，与阶段一中的 M6 里程碑分别编号。

## 范围

- 根据题库参考答案的结构生成可打印答题卡，按必做题、个性化、历史回顾分区。
- 保证题号、小题号、空位与学生实际试卷一致，支持多空题、多页打印和移动端预览。
- 后续按实际需求接入视觉模型读取答题卡，与既有确定性判分、教师复核和画像更新衔接。
- 保存识别、修正及判分依据，避免重复提交或不确定结果污染画像。

题库内容和答案的审核、自动组卷池准入仍由阶段五维护；批量题目导入仍由阶段四维护。本阶段不替模型或教师猜补缺失参考答案，不用重新排版改写已有发布快照。
