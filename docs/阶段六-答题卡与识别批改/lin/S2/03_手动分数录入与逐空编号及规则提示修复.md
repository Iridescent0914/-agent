# S2：手动分数录入、逐空编号与规则提示修复

日期：2026-11-18。承接[百炼文本模型接入](02_S2百炼文本模型接入与配置记录.md)。

## 问题与本次范围

真实页面试用发现：分母仍为空位的公式可能与用户希望录入的完整分数不同，已有提交显示为`-156`；学生原始答案的每行标签都显示“第1小题第1空”；预检中的“规则已有明确结果”容易被理解成模型已判断语义不等价。

本次修复输入完整性、受控MathLive同步、显示坐标与预检解释。没有执行真实模型请求，没有修改题库标答/别名、学生既有答案、成绩或画像，没有扩大首批模型候选范围。

## 原有判分规则的依据

规则来自阶段一M4的`m4-grading-v1`，实现位于`backend/app/services/grading/`，原设计和验收记录见[11_M4工作总结与M5交接](../../../阶段一-初版开发M0-M6/开发记录/11_M4_工作总结与M5交接.md)。每道题配置`answer_match_type`和`answer_normalization_rule`，小题组按叶子`item_id`配置匹配类型和`accepted_answers`；实际判分沿用发布快照或已显式采用的标答修订。

| 方式 | 原有含义 | 本次样例 |
| --- | --- | --- |
| `numeric` | 受限AST及Fraction精确有理数比较，另检查已配置格式约束 | `+30`与`30`数值相同，无需模型 |
| `exact` | 按快照执行显式的空白/全角等归一化，再比较文本及已登记别名；不做同义词推断 | `相等`与`一样`、`负`与`负数`未匹配，不等于模型已证明语义不同 |
| 叶子`accepted_answers` | 标答之外明确登记的可接受答案 | 标答`负`若登记`负号`，则`负号`可通过，`负数`不会自动加入 |
| `latex_exact` | 同样源码可直接通过，不同公式形式进入待复核 | 阶段六首批只对其受支持的待定公式形式请求等价建议 |
| `choice` / `group` | 选项规范化匹配；组内按稳定ID对齐，各组仍对应一个Attempt | 不按显示顺序猜测答案归属 |

旧预检“规则已有明确结果”是程序分支状态，表示旧判分器返回了`is_correct=False`，不是模型结果。阶段六先保留原判分依据，首批候选没有把所有精确文本不匹配交给模型。若后续扩大到短语语义，应单独定义范围与人工标注样本，不能在本次界面修复中静默放宽正式判分。

本次将精确文本不匹配的提示改为“本空按精确文本规则未匹配标答或已登记别名；尚未进行语义等价判断，可人工复核”；数值匹配改为明确说明“按数值规则计算结果相等”。侧栏增加本空判定方式。返回原因码、候选门禁与正式评分逻辑保持一致。

## 分数录入与完整性

`MathAnswerInput`原先在numeric模式输出ASCII Math，但接收外部值时始终按LaTeX回填；模板中的占位符与受控输入回写也未独立保护。浏览器复现中，完整的`\frac{-1}{56}`导出为`(-1)/(56)`，而含未填分母的`-\frac{1}{\placeholder{}}56`属于不完整公式，不能作为负整数提交。

修改如下：

- 未完成模板保留带`\placeholder`的LaTeX原文，不将其转换成看似完整的数值；显示“公式尚未填写完整”的提示。
- 初始值和外部变更按实际格式恢复：ASCII先通过MathLive的`convertAsciiMathToLatex`显式转换，含LaTeX命令的值直接恢复，且静默更新以避免循环通知。回归确认`setValue`即使传入format选项仍按LaTeX读取，不能仅依赖其选项类型宣称格式恢复有效。
- 自身输入的父组件回显不重置公式结构或光标；异步加载MathLive使用最新值与禁用状态。
- 新提交和“修正学生答案”保存前递归检查逐空答案，公式包含占位空位时阻止发送请求；原有后端遇到未完成/非法算式仍为待复核，不把它判成某个整数。
- 输入框提示先填分子，再按Tab切换分母或点击分母位置。普通输入也可直接录入`-1/56`。

不对已有`-156`尝试猜测还原。它也可能是学生实际写出的整数；需要教师对照原作答，使用“修正学生答案”记录更正。现有修正流程保留AttemptRevision并重算画像，不能直接改历史原始值。

## 小题和空位编号

学生作答按契约只需保存`item_id`和`answer`，不要求复制标答坐标。原`AnswerView`使用`subquestion_no ?? 1`和`blank_no ?? 1`，导致缺少坐标的学生答案全部显示为第1小题第1空。

新增公共`answerUnitCoordinates`：规范ID如`sub_7.blank_3`解析为第7小题第3空；旧数字ID如`9`解析为第9小题；非规范ID优先采用有效显式坐标或按同ID找到的参考答案坐标，再使用兼容性回退。显示保留原数据顺序，不重排、不改写存储。

`AnswerView`、手动编辑器和等价侧栏统一使用此逻辑；批改页及作答证据抽屉另传入当时有效标答供旧结构匹配。历史答案无需迁移即可正确显示规范ID的坐标。手动编辑行增加`data-item-id`方便逐空定位与回归验证。

- 检查标准：未填分母时无法提交；分子`-1`、Tab、分母`56`保留负分数；切换普通/公式输入后结构不丢失；原始答案按`sub_2.blank_2`、`sub_5.blank_1`和旧数字ID展示正确标签；等价侧栏与质量反馈回归不写正式成绩。

开发容器挂载源码，前端刷新后可验证；后端reload加载新的预检文案。现有作答修正应由教师显式操作，不需要重新组卷才能修正显示问题。
