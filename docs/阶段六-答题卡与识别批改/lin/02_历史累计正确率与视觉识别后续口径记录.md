# 历史累计正确率与视觉识别后续口径记录

日期：2026-11-19。

本轮在既有学生画像中增加全历史累计正确率，为后续本卷与学生历史表现比较提供基础。当前未接入新的真实视觉调用，不新增模型自动接受或异常判断。

## 1. 最新需求与本轮范围

视觉模型只负责读取答题卡学生答案，不发送标准答案，不解题或纠正学生答案。提取后衔接规则判分、必要的等价判断及既有确认流程；等价模型只比较标答和学生答案，不接收题干。

## 2. 累计统计口径

```text
累计正确率 = 当前判定正确的有效作答数 / 当前已确认的有效作答数
```

- 统计所有年级、章节和作答时间，不受画像页面年级、章节筛选或最近错题展示数量限制。不将各知识点正确率简单平均，也不用掌握度EMA或素养分替代。
- 单位为一次 `Attempt`，即题库的一道题组。多空题仍按既有整组结果计一次；一组12空即使11空对、1空错，也不按11/12计算这个指标。此处不改变评分规则。
- 同一道题的不同次练习各计一次，同时返回“不同题目数”用于区分练习次数与去重题数。
- 每次作答只计当前判定，并要求当前 `AttemptRevision` 存在；多次改判不累加次数。自动确认和教师确认均可计入，结果必须为明确布尔值。
- `needs_review` 单独显示待复核数，不计入答对、答错或分母。尚未识别或提交的纸卷没有 `Attempt`，不算已经答错。
- 未发布、撤回/失效、被新版替代的试卷和归属损坏、快照无效、当前修订缺失等证据不计入；汇总为排除记录数。沿用已有证据校验，不读取当前题库内容重写历史。
- 用户要求“全部题目”，因此有效确认的历史计算题、解答题也纳入累计指标；原知识点掌握度、素养、回顾状态的适用题型不扩大，原 `summary.valid_attempt_count` 仍遵循旧画像口径。两个计数可能不同。
- 分母为0时返回 `accuracy=null`、页面显示“—”；有确认记录且全部答错时才返回0、显示0.0%。

例如第一知识点10次作答答对9次，第二知识点1次答错：全历史正确率为9/11≈81.8%，不是两个知识点90%和0%的平均值45%。

## 3. 实现与查看

```json
{
  "historical_accuracy": {
    "scope": "all_history",
    "counting_unit": "attempt_question_group",
    "confirmed_attempt_count": 11,
    "correct_count": 9,
    "incorrect_count": 2,
    "distinct_question_count": 8,
    "pending_review_count": 3,
    "excluded_attempt_count": 2,
    "accuracy": 0.8181818181818182
  }
}
```

示例仅用于说明接口，不是实际学生数据。`distinct_question_count` 按纳入分母的已确认作答去重。

## 4. 对0.6候选系数的评估

未来比较可表示为：

```text
本卷正确率 < 本卷之外历史累计正确率 × k
```

两边必须采用同一题组单位和明确的判定覆盖口径。本轮页面累计值包括本卷已经确认的结果，因此未来不能直接把该显示值当作本卷比较基线；应按试卷实例排除当前卷，或在本次提交前冻结基线，避免本卷影响自己的参照值。

建议将 **k=0.6作为保守的初始候选**，而非已验证的最佳参数：

| 历史正确率 | k=0.5时提示线 | k=0.6时提示线 | k=0.7时提示线 |
| --- | --- | --- | --- |
| 80% | 40% | 48% | 56% |

0.6允许较明显的正常波动，较0.7更少因新知识点或难题触发提示，代价是可能漏掉较小幅度的异常。它只是启发式系数，不是置信概率，不能保证识别质量。

单靠乘0.6仍不能判断“新知识点作答低分”是否合理。未来落实异常功能前，至少需：

1. 设定历史已确认样本量和本卷已判定覆盖率下限；没有历史或样本很少时不据此报警。
2. 记录本卷题组的历史知识点覆盖情况；新知识点为主时降低该比较的适用性或交由教师核对，不能直接认定OCR错误。
3. 保留原始图像、抄录和判分依据；低分只提示核对，不自动改分，不将其当作“提取有误”的人工标签。
4. 用真实试卷与教师标注比较误报、漏报和复核工作量，再确定是否采用0.6或调整系数。按卷识别错误率与学生答题正确率分别定义分母和阈值。

以上均为后续方案，当前未增加配置、比较逻辑、异常提示、整卷错误字段或自动接受行为。
