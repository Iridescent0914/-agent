本阶段接入两项相互独立、可以分别评测的能力：

1. **结合题干的答案判断**：文本模型接收发布题干中相关条件、目标空位及本空标答/学生答案，判断本空可接受、不可接受或无法确定；不接收解析、其他空答案、身份或画像。旧版无题干等价任务保留历史解释。
2. **答题卡答案提取**：视觉模型读取学生实际书写的答案，不接收标准答案，不解题、不补全、不根据预期结果改写笔迹。

两项能力都保留模型原始输出和已有人工核对记录，先以建议模式试运行。根据真实样本质量决定是否自动采用，以及学生作答正确率异常低时提示核对，均属暂缓事项；低分不能直接推断模型出错。

## 二、边界、数据单位与总体流程

### 1. 与其他阶段的边界

- 阶段四负责原始题目资料的提取、标签、题图、答案处理、教师审核和正式入库。
- 阶段五负责题库答案治理、审核与自动组卷池准入。
- 阶段六读取经过审核的题目与本次有效标答，处理学生作答采集、等价建议、采用与复核。
- 阶段四的模型答案生成或预审不能替代本阶段的等价判断评测，也不能自动批准学生判分。
- 可复用模型调用、预算、任务恢复的基础设计；不同任务分别保存配置、提示词、状态和质量结果，不直接复用整条文档导入流水线。
- 本阶段不为接入模型放宽题库入池条件，不扩展证明题或复杂解题过程自动评分。

### 2. 标识与版本

最小业务标识为 `(paper_instance_item_id, item_id)`；展示题号使用原卷 `order_no`，小题和空号使用参考答案的已有坐标。不能按页面出现顺序猜配，也不能因答题卡按模块展示而重新编号。

模型任务至少绑定：试卷实例及版本、布局版本、学生答案输入版本或哈希、实际采用的标答与规则版本或哈希、模型与提示词版本、采用策略版本。异步结果返回后必须检查这些依据是否仍然有效；教师已修改答案、切换标答或更新试卷时，旧建议只留审计，不能覆盖新修订。

标准答案按现有 `reference_source` 机制解析，可能来自发布快照，也可能来自已锁定的题库答案修订。打印结构与本次判分标答的空位若不一致，应明确阻断并复核，不能通过模型猜测补齐。

### 3. 流程

```text
手工录入 ─────────────────────────────┐
                                      ↓
多页答题卡 → 归属与完整性检查 → 视觉抄录 → 学生答案
                                             ↓
                                         规则判分
                                             ↓ 必要且获准时
                                       大模型等价建议
                                             ↓
                                  人工复核／有限自动采用
                                             ↓
                              AttemptRevision → 画像刷新
```

模型调用不持有业务数据库长事务或学生行锁。先保存任务和输入依据，再调用供应商，返回后做版本校验与短事务写入。fake 只用于开发和自动化测试，不能作为真实效果验收或开放自动采用的依据。

## 三、等价判断与视觉抄录的任务契约

### 1. 等价判断

- 新版模型业务输入为发布题干中的相关条件和明确目标空位，以及本空标准答案、学生答案；服务端附加无业务含义的请求ID，不发送其他空答案、解题过程、解析、身份或整份试卷。
- 在标准化和已登记别名匹配之后，再判断是否需要模型；批量请求也必须逐单元明确对应，不能将多个空合并成无边界文本。
- 输出语义为 `equivalent / not_equivalent / uncertain`，短说明用于核对，不要求或保存模型隐藏推理过程。
- 只判断两段答案是否等价；数学等价与是否满足题目格式要求分别处理。服务端已有的单位、最简形式等约束不能被模型覆盖。
- 变量条件、定义域、答案顺序或语境缺失时允许 `uncertain`。不因不给题干而强迫模型猜测条件，也不默认任何形式的数学等价都可正式判对。
- 可靠的数值不等、选项不同及明确的格式违规仍由规则处理；模型只处理S0列入范围的待判定形式。
- 按小题组的叶子单元接入，不能只在整组 `needs_review` 时调用：现有整组规则可能因其他空明确错误而提前得到整组错误结果。

### 2. 视觉抄录

- 输入为受控的答题卡图片与不含标答的槽位规格；只提供必要的试卷、页和空位对应信息。
- 不向视觉模型发送标准答案、评分规则、解析或学情。学生实际姓名等非必要信息在外发前移除或遮盖。
- 逐空区分可读、明确留白、图片缺失、字迹不可辨和涂改歧义；沿用现有状态语义，具体单元级结构在S0冻结。
- 保留学生原写法，允许明确规定的无语义变化的排版转换；不能把 `1/2` 改写成 `0.5` 后就称为准确抄录。
- 先核对短码、版本、页码、总页数和空位覆盖，再合并答案。缺页、重复页和错位必须独立记录。
- 不以模型自报置信度代替人工真值，也不单凭高置信度自动生效。

| S7 | 有限自动采用与持续抽检 | 服务端策略开关、抽检、暂停与修正路径 | 仅对通过验收的范围生效 |

```text
S0 → S1 ┬→ S2 等价判断 ─┐
        └→ S3 视觉识别 ─┴→ S4 → S5 → S6 → S7
```

S2与S3可独立试验；建议先用人工确认的答案文本验证S2，再接入视觉抄录文本，以便定位错误来源。S1应提供最小反馈能力，S4再完善教师工作台与汇总统计，不能到S4才开始保留原始输出。

**工作内容**

- 提供最小的反馈保存与查询能力，记录核对人、时间、理由及人工正确结果。

服务重启后记录可查询；并发修改有版本保护；错误响应不能转成学生答错；fake不进入正式采用。复用原始结果后仍能分别核对两种模型的正确性。

**当前状态：建议链路、百炼文本HTTP与预算适配已实现，真实质量验收未完成。** 放行通过语法和约束检查的公式匹配填空候选，以及S5-A新增的受限短中文术语候选；其他明确规则结果、超范围形式及未核对识别文本保持现有处理。批改页可逐空预检、生成建议、查看记录并保存质量反馈。整份作业视觉抄录后的统一调度及教师按题采用已在S5-A实现，不新增独立答案对试验页面。

**工作内容**

- 从人工可靠录入或离线样本开始，不依赖视觉识别。
- 增加按单元发起、查询、重试等价判断的领域服务与内部入口。
- 基于原因和题目规则确定模型候选范围，保留现有确定性引擎，不把所有规则判错结果都送模型。
- 严格限制外发字段，仅比较标准答案与学生答案；对含指令的答案文本同样按待比较数据处理。
- 展示原始答案、模型三态建议及人工核对入口，默认不改变当前最终结果或画像。

**交付与验收**

覆盖正确等价、明确不等价、条件不足、格式违规、别名、多空对齐、非法JSON、超时和旧版本结果。请求测试证明不含题干、解析、学生身份及其他空的答案。模型不确定不自动记错。

### S3：多页视觉识别独立接入

**当前状态：S3-A～E工程链路已实现，真实质量未验收。** 固定分页产物与照片管理沿用原学生版整卷打印，S3-D提供纸面身份/槽位校验、逐页任务、调用审计、租约恢复、模拟与百炼真实HTTP及累计费用控制。S3-E新增整卷合并、逐页逐空核对与不可变修订，明确确认后复用现有判分和画像事务；旧单图创建、提取、提交HTTP退休，历史记录和既有作答复核保留。下一步用已成功提取的结果在前端核对并录入；整卷等价调度和真实质量验收仍待推进。详见[S3-A](S3/01_S3逐空清单与多页合并离线准备记录.md)、[S3-B](S3/02_S3固定分页PDF与冻结产物记录.md)、[S3-C](S3/03_S3作答照片采集与有效页管理记录.md)、[S3-D模拟](S3/04_S3逐页视觉协议与模拟任务记录.md)、[S3-D接入](S3/05_S3百炼视觉HTTP与费用控制接入记录.md)及[S3-E](S3/06_S3整卷抄录核对与批改录入记录.md)。

**工作内容**

- 扩展单图流程，建立同一试卷的页面集合、页身份、图像哈希和逐页处理状态。
- 支持显式补页、重拍、失败页重试；合并时保留原图、来源页与原始抄录。
- 根据槽位规格逐空接收结果；空位缺失、重复、超范围或归属冲突进入复核。
- 原图与识别文本并排展示；教师可以确认抄录或纠正抄录，纠正不覆盖模型原始结果。
- 首轮可采用整页识别；是否增加定位、裁剪、二维码等由样本效果决定，不预设其已完成。

**交付与验收**

覆盖单页与多页、三类题目分区、跨页续题、多空、留白、负号、分数、涂改、模糊、错码、缺页和重复页。缺页不等于留空；同一真实练习补拍不增加学习次数；外发内容和提示词不含标准答案。

### S4：复核、质量统计与异常提示

**S4-A只读表现参考已实现，其余仍暂缓。** 只展示本卷与其他试卷历史统计，不作异常判定。新的视觉识别错误反馈按整份试卷记录，不把已有逐空诊断反馈直接当作整卷错误字段。低正确率比较拟使用“本卷正确率 < 本卷之外历史累计正确率 × 系数”，两者均按题组；0.6为候选而非已验收阈值，还需历史样本量、判定覆盖率及新知识点占比保护。无历史不比较。当前不新增整卷错误字段、质量接受开关或告警。

**工作内容**

- 完善原图、抄录文本、等价建议、规则结果与人工最终决定的复核工作台。
- 分别统计识别质量与等价判断质量，保留样本量、未核对数、无法确定数和自动处理覆盖率。
- 区分模型错误、标答问题、人工录入问题和后续答案变更；教师修改一次不能直接等同于模型错一次。
- 增加学生作答正确率低等提示，显示触发原因、分母与已判定覆盖率。
- 采用前若按规则结果和模型建议计算低分提示，必须标为“暂估正确率”，同时显示待判定数；它不是最终学情，不能直接写入画像，也不能把未知项补成错误来触发告警。
- 为错码、缺页、空位冲突等结构问题设置阻断；为低学生答对率设置疑似异常提示。

**交付与验收**

同一条结果可以追溯到输入、输出和人工判断。识别错误但等价模型对其实际输入判断正确时，只归因识别错误。标答有误单独记录并进入既有答案审核修正流程，不能自动覆盖标答或计为等价模型错误。

### S5：业务闭环联调

**当前状态：S5-A工程闭环及S5-B上下文判断已实现，真实样本联调与独立质量验收未完成。** 详见[S5-A记录](S5/01_整卷等价判断调度与教师采用记录.md)及[S5-B记录](S5/02_结合题干的答案可接受性判断记录.md)。本轮按用户确认范围衔接统一调度、题干判断和教师采用，自动采用或错误率阈值仍暂缓。

**工作内容**

- 在阶段四形成稳定正式入库能力后，用其审核后的题目做端到端联调；现有题库可用于此前内部开发。
- 串联多页上传、逐空抄录、规则判分、必要时等价建议、教师确认、正式修订和画像刷新。
- 人工确认与正式采用使用既有提交和修订机制；不为每个空另建一条 `Attempt`，不暗改原有整组评分语义。
- 防止过期模型结果覆盖教师修改；标答版本变化时按明确动作重新判断或重新评分。
- 识别补拍、模型重试、重复点击与教师改判分别验证幂等，避免重复增加作答、修订或画像影响。

**交付与验收**

完成手工与图片两条输入路径、旧新试卷版本、多空部分待判定、教师修正、撤销确认、标答修订和异常回滚。网络等待不长期占用事务；未采用建议不写入有效画像；真实教师确认才标记为 `teacher_confirmed`。

### S6：真实样本与阈值验收

**工作内容**

- 固定模型、供应商、提示词、结构化响应契约和布局版本，分别评测两项任务。
- 开发样本与独立验收样本分开，避免只在反复调过提示词的题目上宣布通过。
- 覆盖不同答题者、书写习惯、题型、答案形式、页数与拍摄条件；同一图片的多个空不能简单当作独立图片证据。
- 统计质量、覆盖率、异常、延迟、费用及教师复核工作量，同时报告样本不足的范围。
- 根据教师可接受的误差、样本量和统计不确定性冻结阈值；低错误率但几乎全部拒答也不算可用。

**交付与验收**

形成可复现报告、明确的通过范围、禁止自动采用范围及异常处置方式。fake、合成图和模型自报置信度不能替代真实手写验收。阈值通过只产生准入结论，不自动打开生产开关。

### S7：有限自动采用与持续抽检

**工作内容**

- 按任务类型、题型、答案形式及模型版本配置服务端策略，不使用覆盖全部情况的单一开关。
- 单条结果还须通过输入归属、版本、完整性、确定结论和异常检查；整体质量达标不表示每条结果必然可信。
- 自动采用独立留痕，并通过受控领域服务追加修订、更新画像；不得伪装成教师确认。
- 对自动采用结果持续抽检，既包含随机样本，也保留定向检查问题样本；统计时区分抽样方式。
- 模型或提示词更新重新评测；超阈值时暂停该范围的后续自动采用，恢复为人工复核。
- 已生效结果发现错误时生成待处理清单，通过正式修订纠正并重算画像，不删除历史或无审计地批量改判。

**交付与验收**

验证未达标无法启用、开关可关闭、异常可阻断、教师可修正、重复采用幂等及策略版本可追溯。暂停自动采用不影响原有手动录入、规则判分和教师复核。

## 六、人工反馈与质量指标口径

### 1. 最小反馈信息

以下为业务含义汇总；字段与状态以[S0契约](S0/需求与状态契约.md)为准，具体表结构在S1实现，不表示当前已新增字段：

| 信息 | 含义 |
| --- | --- |
| `review_status` | 未核对、确认正确、确认错误、仍无法确定；两类模型分别记录 |
| `is_error`（若保留） | 可空布尔值；未知为 `null`，不能默认 `false`；与反馈状态保持一致 |
| `error_type` | 抄录、归属、留白误识别、等价误判、标答问题等归因 |
| 人工正确结果 | 人工抄录文本或人工等价结论，不与题库标准答案字段混用 |
| 核对人、时间、理由 | 形成可追溯反馈；更正反馈时保留历史 |
| 采用状态与依据 | 尚未采用、已采用或已失效等，和模型是否判断正确分别记录 |

核对标签必须对应当时的模型输入。OCR抄错导致后续判分错误，不代表等价模型对其收到的答案也判断错误；学生答案后来被修改，也不应追溯记为旧模型出错。

### 2. 指标与分母

| 指标 | 统计口径 | 注意事项 |
| --- | --- | --- |
| 识别抄录准确率 | 人工确认可辨且被正确抄录的单元数 / 人工确认可辨的单元数 | 对可辨答案输出缺失或无法辨认不算正确，不从分母排除 |
| 识别状态准确率 | 识别状态与人工状态一致的单元数 / 有人工状态标签的单元数 | 分开检查留白、缺失、不可辨与歧义 |
| 等价确定结论一致率 | 与人工结论一致的确定结论数 / 人工可判且模型给出确定结论的单元数 | 同时报告模型拒答率和覆盖率，不能隐藏难例 |
| 自动采用错误率 | 已人工复核且确认为错的自动采用单元数 / 已人工复核的自动采用单元数 | 分任务及版本统计；抽样偏差和样本量需说明 |
| 学生作答正确率 | 最终确认答对题组数 / 最终确认已判定题组数 | 历史累计指标已实现；本卷异常比较暂缓，未来保持同一单位，待识别、待判定不算错 |

逐空正确率可用于模型诊断和离线评测，不与画像累计正确率混用。后续识别错误记录按整卷，不能直接拿逐空错误率充当整卷错误率；整页和整份答题卡完整率另行记录，避免少量错位影响整卷却被平均值掩盖。

### 3. 阈值与异常

S0预留识别质量、等价质量、自动采用错误率、最小评测样本量、最小覆盖率、学生低正确率提示等配置。具体数值在S6结合真实样本和教师反馈确定，本计划不指定默认的 `xx`。

2026-11-19先实现画像全历史指标，未启用以上质量/异常配置。低正确率比较候选系数0.6及新知识点影响的评估见[记录02](02_历史累计正确率与视觉识别后续口径记录.md)；将来应排除当前试卷再构造比较基线，不能直接使用含本卷的页面累计值触发异常。

“错误率低于阈值”用于开放经过验证的范围；“学生正确率低于阈值”用于疑似异常提示，两者不共用字段或阈值。样本不足时不能宣布质量达标，未核对结果不能当成零错误。模型自报置信度仅作辅助展示。

## 九、首批待确认事项

1. 首批希望自动处理的答案形式，以及遇到条件不足时接受人工复核的范围。
2. 教师对错误采用、漏判、复核工作量和模型费用的可接受程度；三类指标各自的阈值目标。
3. 多页照片的上传方式、页身份、补拍和缺页处理，是否需要升级答题卡布局版本。
4. 真实手写样本来源、人工标注负责人、资料外发范围和保留期限。
5. 模型供应商、具体版本、可用输入格式、服务端预算和失败处理配置。
6. 从内部单教师试验转为多教师试用时，可信服务端身份和任务归属的实现方案；现有操作人文本不能充当授权凭据。

这些事项按阶段逐步确认：不妨碍先编写契约草案和开发fake基础，但涉及真实调用、教师试用或自动采用时，必须落实对应条件。
