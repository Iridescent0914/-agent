# S3-B：固定分页PDF与冻结产物记录

开始：2026-11-18；收尾：2026-11-19。

## 1. 交付内容

新增后端固定A4分页的 `answer-card-v3` 答题区模板，保存内部PDF字节、PDF摘要、逐页空位清单及其摘要。学生仍通过现有“打印 / 保存 PDF”得到**前面题目、后面答题区的一份完整试卷**，不增加单独生成或下载答题卡的用户流程。

2026-11-19按实际打印需求调整：固定PDF仅作为后台答题区模板。首次点击整卷打印时，阶段六内部功能若启用，后台生成或复用模板，浏览器取得各页矢量图后接在题目后面，再统一打开打印对话框。题干、公式和题图沿用现有学生版渲染。无需教师另外下载、打印或拼接文件。

保存的摘要和不可覆盖字节针对**答题区模板**，不是浏览器最后导出的整卷PDF；题目正文页数由原有打印流程决定。目前不保存整卷PDF字节。答题区页码按“答题卡第1～N页”计，不包含前面的题目页；后续识别只收取相应答题页。

本轮仍未接真实视觉模型或新多页照片上传，不改变正式判分、等价模型候选或画像。S3-A的人工页面计划继续用于离线验证；正式产物有独立的清单契约，不能把人工计划直接标记为正式产物。

## 2. 渲染与分页

后台模板使用已有PyMuPDF依赖，不新增服务器浏览器渲染服务或系统字体包。中文用内置CJK字体、ASCII用内置Helvetica混排，避免中文字体把试卷短码拉成过疏的字母。客户端通过本地接口读取各页SVG，字形转为路径，保持模板的文字和几何位置。

- 固定A4页面大小、边距、三列短答案书写区；人工题留更大的整行作答区。
- 保留必做题、个性化、历史回顾及空模块；周总结使用独立模块，旧未分类题也保留。
- 使用发布快照中的题号、小题号和空号，不因分区顺序重新编号。多空可拆成多行；一个空的书写区完整保留在同一页。
- 跨页重复模块和题组上下文；每行都有原题号与小题号。不同页可包含同一题组的不同空，不能包含同一个空的两个有效副本。
- 每页显示作业标题、学生系统编号、试卷短码及内容版本；页脚显示产物编号、产物修订、当前页/总页数和布局版本。
- 使用醒目的“答题卡（答题区域）”标题和四角L形定位标记；定位标记供后续归属与区域定位使用，本轮尚未实现自动裁切。
- 去掉“选项”“答案”等冗余标签，保留必要空号及判断/人工作答提示。

页清单和PDF由同一分页计划产生。每页保存页令牌、每空的业务映射及独立空位令牌、书写区坐标；坐标单位是PDF点，原点在左上角，页面尺寸随清单保存。书写区坐标不包括左侧题号和上方提示文字。

渲染后再次校验：页间空位不重复，并集等于全部清单空位。最多100页、PDF不超过8MB，超限明确失败。长作业标题仅在固定标题区截短，不改变试卷短码和内部绑定。人工判分空位或缺失选择字母仍可以打印，但这些单元的识别阻断原因保留，不因此获得自动识别资格。

## 3. 持久化和版本

新增 `AnswerCardArtifact` 和Alembic迁移 **0034**，承接仓库已有的0033导入审计修复。未修改0033内容。

| 字段 | 含义 |
| --- | --- |
| `paper_instance_id` | 所属学生的已发布试卷实例 |
| `revision_no`、`artifact_code` | 同一试卷的产物修订及纸面产物编号；与试卷内容版本分别计数 |
| `layout_version` | `answer-card-v3` |
| `renderer_version` | 分页实现版本及PyMuPDF版本 |
| `source_sha256`、`dedup_key` | 发布空位结构、显示标题/系统编号、作业类型和渲染版本的摘要与复用依据 |
| `pdf_data`、`pdf_sha256` | 实际下载的PDF字节及其SHA-256 |
| `manifest`、`manifest_sha256` | `stage6-answer-card-manifest-v1` 页清单及摘要 |

PDF和清单在同一数据库事务内保存，不需要额外公共文件目录，也不会出现文件已写入但业务记录回滚的半成品。PDF字段延迟加载，列表请求不读取全部PDF字节。

生成时锁定试卷行并核对试卷仍有效、学生未归档、请求内容版本一致。相同来源与渲染版本复用原产物；页面刷新不会自动创建，读取页面图或内部下载不会重新生成模板。标题等实际打印内容或渲染版本变化时，生成新的产物修订，旧PDF和清单保留。合并打印和定位标记调整后，渲染版本升级为 `answer-card-fixed-v2-pymupdf-*`。

数据库触发器拒绝产物表的UPDATE/DELETE，包括直接SQL修改。下载读取已保存字节并校验摘要，返回清单前也校验其摘要。试卷后续失效时禁止生成新产物，但仍可查看原产物，作为历史依据；下载不恢复试卷有效状态。

摘要用于完整性和复用检查，不是密码学签名，也不替代后续照片提交时的服务端归属、有效性和权限检查。

## 4. 接口与前端

接口前缀：

```text
/api/v1/internal/stage6/paper-instances/{paper_id}/answer-card-artifacts
```

- `POST`：显式生成或复用，JSON请求为 `{"expected_version_no": 1}`。
- `GET`：只读列出该试卷最近50个产物，按产物修订倒序。
- `GET /{artifact_id}/manifest`：返回该试卷的冻结页清单。
- `GET /{artifact_id}/pdf`：下载该试卷的已存PDF，附带文件名和PDF摘要ETag。
- `GET /{artifact_id}/pages/{page_no}/image`：返回保存PDF的指定页SVG；文字转为路径，不加载外部字体或资源，越界页返回404。

接口沿用阶段六内部门禁：`APP_ENV=development/test` 且 `STAGE6_ENABLED=true`。尚无可信教师归属鉴权时不开放生产环境；不能只凭知道产物ID跨试卷下载。

前端只有原有“打印 / 保存 PDF”入口。点击后检查内部门禁，启用时准备模板、校验页清单与试卷版本、顺序加载全部页图，成功后才打开整卷打印；同一页面再次打印直接复用已准备内容。加载失败时保留题目和原答题区，显示错误，不打开缺页的打印对话框。切换试卷会取消旧请求，旧结果不能触发新试卷打印。

题目页继续使用原A4边距；答题区使用命名A4页面、零额外页边距和固定页面尺寸，逐页另起新页，防止题目与答题区同页、图片二次缩放或被分页切开。题图及答题区页图加载完成后才打印。内部功能未启用或旧部署无该接口时，继续原“题目+另页答题卡”的整卷打印。

内部PDF读取接口保留供保存依据和开发核对，不再显示独立打印/下载入口。

## 5. 本地启用与查看

本轮只迁移了隔离测试库，没有执行业务库迁移，也没有重新创建业务容器。业务后端需先应用0034迁移。

项目Compose的后端启动命令会先执行 `alembic upgrade head`；本地 `.env` 中 `STAGE6_ENABLED` 已启用且不再更改环境变量时，可运行：

```powershell
docker compose restart backend
```

若同时修改了 `.env`，需重新创建后端以加载环境变量：

```powershell
docker compose up -d --no-deps --force-recreate backend
```

之后刷新某份有效试卷的打印页，点击原有“打印 / 保存 PDF”，保存整份学生版试卷。使用A4实际尺寸打印，关闭打印对话框附加的浏览器页眉页脚。前端采用源码挂载的开发环境可直接刷新；无需重新组卷，也无需填写视觉API。

忽略目录下的 `.runtime/answer-card-v3.pdf` 已更新为整卷模拟样例，同内容另存 `.runtime/student-paper-with-answer-card.pdf`；共8页，前1页是模拟题目、后7页为实际后端模板生成的答题区。内部答题区模板另存 `.runtime/answer-card-v3-template.pdf`。题目首页、答题区首页与末页PNG分别为 `.runtime/student-paper-first.png`、`student-paper-answer-start.png`、`student-paper-last.png`。它们不包含真实学生作答，也不随Git共享；不能用于证明真实识别准确率。
