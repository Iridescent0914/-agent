# S3-E：整卷抄录核对与批改录入

日期：2026-11-19。承接[百炼视觉HTTP与费用控制接入](05_S3百炼视觉HTTP与费用控制接入记录.md)。

## 本次问题与范围

用户已反馈视觉调用和答案提取成功，但提取结果只在逐页任务中展示，尚未成为正式作答。原页面还提供旧单图识别入口，阶段六状态读取失败时也会回退到旧流程，容易误用旧配置和旧超时设置。

本次补齐“当前有效页结果 → 整卷核对清单 → 人工核对/修正 → 确认录入 → 现有判分和画像刷新”。不在打开页面、刷新、合并或保存核对时调用模型，也不自动提交用户现有作答。

## 操作步骤

1. 在原“答题页照片管理”中选择实际打印的产物。已经提取成功且仍有效的页面可以直接使用，无需重跑或重新支付调用费用。
2. 填写核对人及操作原因，在第5块点击“合并最新整卷提取结果”。必须收齐全部有效页，每页最新任务均已有有效结果。
3. 对照原图检查题号、小题号和空号；逐空修正文本或明确标记留白。原始抄读另行保留，不随修正覆盖。桌面端原图和答案并排，手机端上下排列，可放大图片。
4. 每页勾选已核对纸面编号及全部答案，点击“保存核对清单”。修改答案会取消该页在浏览器中的核对勾选，须重新检查。保存只生成核对修订。
5. 勾选整卷确认，点击“确认录入并判分”，再进入“查看批改结果”。只有这里创建正式Submission、按题组创建Attempt和判分修订，并刷新画像。后续改答、改判及重评分使用现有批改页。

无法辨认、缺失和歧义不能自动补成留白或错误；确认前必须处理成明确作答或明确留白。纸面身份有冲突时阻断；模型没看清编号时由人工逐页对照确认。模型置信度不触发采用。模拟结果即使被手工改成完整答案，仍不能录入正式成绩。

## 保存结构与一致性

新增迁移`0037`，承接`0036`：

- `answer_transcriptions`：每个照片集合一份当前清单，含修订号、输入摘要、整卷来源、原始/有效逐空抄录、已核对页及最终Submission关联。
- `answer_transcription_revisions`：每次合并、保存和录入都保存完整状态快照、操作人、原因、时间；数据库触发器禁止修改或删除历史。正式录入后当前清单也不能覆盖或删除。

清单绑定冻结产物、照片集合修订、每页照片哈希和归属修订、各页最新任务ID/修订/结果，以及核对时的有效评分标准摘要。补拍、切换有效页、重新提取、照片过期、模型配置变化、试卷失效或标答变化后，旧清单不可保存或录入，必须重新合并及核对。同样输入重复合并只复用清单，不清除已保存的人工修改。变更输入后合并会重建有效清单，旧修正保留在历史中，不自动套用到新结果。

确认事务先锁学生，再锁试卷、集合及评分参考，沿用既有锁顺序。完整覆盖所有题目和空位之后，复用现有统一判分函数，不按空新增Attempt。一题部分留白保留group中的null；整题留白使用现有blank状态。录入来源仍为`image`，附件及评分依据关联核对清单和保存时的修订，明确标记已核对抄录，不能伪装成人工键盘录入或误走旧识别待确认接口。

Submission、Attempt、AttemptRevision、核对提交修订及画像在同一事务完成；任一步失败全部回滚。相同已确认版本的网络重试返回同一份作答，不重复增添练习和判分修订；已有其他作答则拒绝覆盖。正式清单提交后追加submit修订，评分依据引用的是提交前已保存的核对版本。重评分和后续人工改答保留识别确认及清单来源。

批改页展示本次提交绑定的各页原图和来源。以后补拍不会悄悄替换已提交的证据照片；原图过期清理后仍保留抄录、修订及成绩，明确显示原图已清理。

## 接口与旧入口收口

以下接口均位于`/internal/stage6/paper-instances/{paper_id}/answer-card-artifacts/{artifact_id}/page-collection`之下：

| 接口 | 用途 |
| --- | --- |
| `GET /transcription` | 读取当前清单、原图来源、阻断原因和修订摘要；不产生写入 |
| `POST /transcription/merge` | 合并全部有效页；携带集合版本和清单预期版本 |
| `PUT /transcription` | 完整保存逐空修正及逐页核对，带预期修订与输入摘要 |
| `POST /transcription/confirm` | 明确确认保存版本并录入；带预期修订、输入摘要和true确认 |

保留现有内部开发/测试环境限制。核对人文本用于审计，尚不能充当可信身份或教师权限；本次不宣称已具备多教师生产授权。

前端删除旧单图上传、提取和提交操作，阶段六关闭或读取失败时明确提示，可重试，不再回退旧界面。旧单图创建、extract、commit HTTP统一返回410，阻止旧页面继续消费API；旧记录、原图读取、清理及已存在作答的复核能力保留。旧M6服务保留用于历史兼容，不再作为新采集通道。其历史测试显式覆盖退休门禁以复现旧夹具，正式门禁由本次新增测试独立验证。
