# 参考答案驱动的分区答题卡排版记录

日期：2026-11-16。

## 1. 需求与问题复现

本次需求：答题卡按题库参考答案组织小题和空位，并明确分为“必做题、个性化、历史回顾”三块。后续视觉模型读取答题卡、答案比对等工作继续记录在阶段六。

原打印页把每组题的所有答案单元放在两列中的一条横线上；每个单元至少 80px，却没有换行规则。用现有有理数001、020、050组成的样例，共13＋24＋2个作答位，可复现答题栏重叠、横向溢出与PDF裁切；学生还能看到 `sub_2.blank_1` 等内部编号。原答题区只是跟随正文的内容块，没有三类题目分区。

## 2. 数据口径

### 参考答案决定结构

题库的结构化参考答案 `answer-units-v1` 是小题、空位的来源。打印已发布试卷时，从 `PaperInstanceItem.answer_snapshot` 读取当时保存的参考答案结构，不按题干横线重新猜空，也不读取当前题库答案覆盖历史试卷。

打印接口仅投影每个单元的 `item_id`、`subquestion_no`、`blank_no` 和作答区类型，按小题号、空号数值排序；参考答案正文、备选答案、评分规则和解析不进入学生答题卡。原有 `blank_ids` 字段保留；新增 `subquestions` 供前端分行。布局版本更新为 `answer-card-v2`。

历史单答案保留 `answer` 单元；旧组答案仅有数字ID或规范的 `sub_N.blank_M` ID时，从已有ID恢复展示坐标，保留原ID，不改写快照。参考答案组为空、单元缺少ID、ID或坐标重复、规范ID与显式坐标冲突时，返回明确错误，避免静默漏空或编造作答位。

### 发布时的选题记录决定模块

从题项的 `selection_audit.source_module` 读取 `required / personalized / history`，不按当前题库的 `is_required` 推断历史试卷角色。答题卡固定依次展示：

1. 必做题；
2. 个性化；
3. 历史回顾。

没有题目的模块仍明确显示“本次无……”。模块内保留原卷顺序，题号始终使用试卷的 `order_no`；不因为分区展示顺序不同而重编号。例如原卷为必做1、历史2、个性化3，答题卡展示1、3、2，但每题仍对应正文原题号。

独立周总结按“周总结”显示。缺少明确模块的旧题显示在“未分类题目”，提示旧卷未保存模块；不误归为必做题，不漏掉这些题目的作答位。

## 3. 页面与打印实现

- 新增 `PrintableAnswerCard`，与题目正文展示分离；正文原顺序及原始题库文本不变。
- 每组题显示原题号、题型、小题数量和作答位数量；小题单独成行，一题多空按“第1空、第2空……”展示。
- 空位使用可换行的网格，桌面和打印为三列，窄屏为两列；网格允许收缩，避免原来的最小宽度把页面撑开。
- 选择题留选项字母作答位，判断题留判断结果作答位，填空题留横线；历史计算、解答题及人工判分单元留较大的作答区。
- A4打印使用14mm页边距，答题卡从新页开始；整张卡和整类题目允许跨页，小题行尽量完整保留。
- 使用可重复的表头，在答题卡续页继续显示作业标题、学生编号、试卷短码、版本及作答说明。
- 每个小题行同时显示原卷题号和小题号，即使跨页后没有上一页的题组标题，也能确定答案归属。
- 清除打印时的应用灰底，隐藏导航和工具栏。学生页面不显示内部空位ID，也不显示参考答案。

## 5. 边界与后续

本次不需要数据库迁移；打印布局从已保存的快照和选题记录计算，不修改试卷、答案、作答或审计。前后端需要一起更新，旧版前端不能完整使用新增的分小题契约。

多页答题卡先解决可读、可写、题号一致及续页身份信息；本次不新增二维码、逐空像素坐标或自动裁剪，也不把打印布局版本当作已验收的视觉识别模板。后续接入视觉模型时，需明确多页上传、短码核对、空位对应和原图复核，再对真实手写样本验收。
