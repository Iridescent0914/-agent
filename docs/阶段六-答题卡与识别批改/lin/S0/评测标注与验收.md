# S0：评测标注与验收准备

日期：2026-11-18。关联契约：[需求与状态契约](需求与状态契约.md)。

> 2026-11-20更新：文本任务以[S5-B结合题干判断](../S5/02_结合题干的答案可接受性判断记录.md)为准；新版离线导出、待标注模板及结果核对见[S5-C记录](../S5/03_真实联调样本导出与离线核对记录.md)。S0时期“不给题干”的口径仅解释历史V1记录。

本文件定义样本和统计口径。S0初版编写时尚未调用真实模型；后续用户已进行小额真实试用，仍没有真实质量通过结论。[模型协议与样例](模型协议与样例.json)仅是合成契约样例；其中无真实图片、真实供应商输出或教师标注，不能计入准确率。[阈值配置示例](阈值配置示例.json)不直接被当前应用读取。

## 1. 分开准备两份金标准

### 1.1 结合题干的答案可接受性

一条样本至少包含：

| 字段 | 说明 |
| --- | --- |
| `sample_id`、`source_group_id` | 去身份化样本ID与来源组，便于同源隔离 |
| `dataset_version`、`split` | 数据集版本及 `development / acceptance` 划分 |
| `reference_answer`、`student_answer` | 实际用于模型比较的两段文本 |
| `answer_context`、`request_sha256` | 模型实际收到的发布题干条件、唯一目标空位及冻结请求哈希 |
| `input_revision`、`reference_sha256` | 固定输入与标答依据，避免用修改后的真值评旧调用 |
| `gold_verdict` | 人工结论：`equivalent / not_equivalent / uncertain` |
| `gold_reason`、`conditions` | 人工说明及类别标签；仅评测保存，不随答案对发送给模型 |
| `annotation_status`、核对人及时间 | `pending / labelled / disputed / resolved`，未解决争议不能充当确定真值 |

新版人工金标准评判的是“学生答案填入实际提供的题干目标空后，是否与本空标答表达相同数学含义并满足要求”。`equivalent / not_equivalent`分别表示本空可接受/不可接受。核对者使用冻结的`answer_context`，不使用后来编辑的题干、标答或学生答案；外发上下文不足时应标`uncertain`。旧V1无题干记录单独保留，不混入新版质量统计。

初期使用现有题库参考答案，人工构造不同写法、明确错误及条件不足案例；这些是开发样本，不声称代表真实学生错误分布。后续加入去身份化真实作答，独立保留验收集。

### 1.2 答题卡图片

一份样本至少包含：样本/来源组ID、数据集版本、真实或合成来源、打印产物ID与哈希、布局版本、预期页清单、图片受控引用及哈希、每页每空的人工状态和抄录、页身份核对结论、拍摄条件、标注人与时间。

每个空的真值绑定 `(paper_instance_item_id, item_id)`，分别记录 `readable / blank / missing / illegible / ambiguous` 和忠实抄录文本。图片的清晰程度与学生作答是否正确是不同维度；不能照题库标准答案填抄录真值。

缺页记录在整份采集样本中，不能批量标注该页学生 `blank`。重复拍摄保留来源关系，并明确当前有效页。图片身份不明的样本可以用于失败路径测试，不能混入“已正确归属”的准确率分母。

真实样本存入受控、默认不入Git的目录；建议在 `data/uploads/stage6-eval/` 下分开保存图像、人工标注和报告。共享文档只记去身份化样本ID、来源类别及复现方法。现有 `.runtime/answer-card-v2.pdf` 是排版样例，不是手写识别金标准。

## 2. 样本覆盖与数据划分

| 类别 | 至少覆盖的情况 |
| --- | --- |
| 等价表达 | 代数展开/因式形式、符号与括号、分数表达、明显不等价、缺少变量条件、无法解析 |
| 规则边界 | 选项不同、数值不同、已登记别名、允许/禁止分数小数等价、格式违规不被模型覆盖 |
| 手写内容 | 正负号、分数线、指数、循环标记、判断符号、多空、明确留白、涂改和难辨字迹 |
| 拍摄条件 | 清晰、轻微倾斜、阴影、模糊、裁切和重复拍摄 |
| 页面关系 | 单页、多页、续题、错短码、错版本、缺页、重复页、槽位遗漏和错配 |
| 组合问题 | 识别错误但后续判断对其输入正确、识别正确但等价误判、标答本身有问题 |

不设置“先攒够固定数量才能开发S1”的门槛。先用少量已核对样本验证工程，再逐步扩展。正式验收所需样本量由S6结合目标误差和不确定性确定，不把小样本零错误当作质量已经达标。

同一来源题的轻微变式、同一学生/答题者的重复拍照、同一打印卡的各页和各空，用 `source_group_id` 关联。开发与验收按来源组隔离，不能把原图放开发集、同图裁剪放验收集，也不能把同一张图的几十个空简单算成几十份独立图片证据。除逐空统计外，还需报告真实图片数、答题者数、来源组数和整卷数。

开发样本允许随问题扩充；独立验收样本一旦用来调提示词，就降为开发样本或形成新的数据集版本，再补充独立样本。争议样本由另一位核对者复查；未解决时保留 `disputed` 并报告，不为得到好看的准确率强行定性。

## 3. 忠实抄录的比较规则

评测比较前仅执行版本化的无语义变化处理，例如明确记录的空白、全角符号和分数排版转换。不得使用本阶段等价模型判断“OCR是否抄对”，否则两项错误相互掩盖。

- `\\frac{1}{2}` 与 `1/2` 可以在受限且已核准的抄录规范化规则下视为同一书写结构。
- `1/2` 与 `0.5`、`x+x` 与 `2x`、`-1` 与 `1` 不属于忠实抄录一致，即使某些写法数学等价。
- 负号、指数、循环范围、括号等不能在规范化时丢弃。
- 多空答案按单元键比较，不将字典整体转字符串比较，也不依赖模型返回数组顺序。
- 选择题的大小写/全角转换可以采用，但必须检查实际选项集合；不把无效字母替换成常见字母。

当前 `evaluate_m6_recognition.py` 仍按已有题号结果及通用字符串规范化评测；它需要在S3/S6升级，不能直接把其旧报告解释为新协议的逐空质量结论。旧示例清单中的0.85等阈值属于旧示例，本阶段不继承为验收标准。

## 4. 指标与分母

每个比率同时输出分子、分母和比率。分母为0时比率为 `null`，不能记作100%或0%。还需报告未标注、争议、未调用、调用失败和无法确定的数量，防止通过排除难例制造高准确率。

### 4.1 视觉识别

| 指标 | 定义 |
| --- | --- |
| 忠实抄录准确率 | 人工可辨单元中，模型可读且抄录匹配的数量 / 人工可辨单元总数 |
| 识别状态准确率 | 模型状态与人工状态一致的数量 / 有已解决人工状态标签的单元数 |
| 可辨答案漏识率 | 人工可辨但模型输出missing、illegible、ambiguous或未返回的数量 / 人工可辨单元总数 |
| 留白误识数 | 人工明确留白却被识别为有内容，以及人工有内容却被识别为留白，分别计数 |
| 页/整卡完整率 | 单页要求归属、本页槽位覆盖和内容状态均通过；整卡还要求页集完整且所有页通过。分别用通过数量除以已标注页数或整卡数 |

对评测集中应调用却失败的页面，其人工可辨单元仍计入抄录准确率和漏识率的分母，并计为未正确提取；服务失败另报。主动挑选未调用的样本不能混入已执行的质量报告，必须报告挑选范围及数量。

完整的字段集合不代表内容均可用：一个含 `ambiguous` 的页面即使响应结构合法，也不是可直接采用的完整页。

### 4.2 等价判断

| 指标 | 定义 |
| --- | --- |
| 确定结论一致率 | 人工确定且模型也确定的样本中，结论相同的数量 / 该类样本总数 |
| 确定处理覆盖率 | 人工确定样本中模型给出确定结论的数量 / 已安排执行的人工确定样本数 |
| 错误等价接受数 | 人工为not_equivalent但模型给出equivalent的数量 |
| 错误不等价拒绝数 | 人工为equivalent但模型给出not_equivalent的数量 |
| 条件不足时的越界确定数 | 人工为uncertain但模型给出任一确定结论的数量 |
| 恰当拒答数 | 人工为uncertain且模型也为uncertain的数量 |

人工为 `uncertain` 的样本单独成层，不混入“人工确定结论”分母。全部输出 `uncertain` 时，确定处理覆盖率为0，不能凭没有错误确定结论宣布模型可用。协议/调用失败既单独记录，也会降低既定执行集合的处理覆盖率。

### 4.3 采用质量、学生正确率与异常

`自动采用错误率 = 已人工复核的错误自动采用单元数 / 已人工复核的自动采用单元数`。S7以前没有真实自动采用，报告该指标为 `null`；S6可以用冻结策略做离线“拟采用”模拟，但必须单独命名，不伪称正式采用。

真实运行抽检区分随机抽检与定向问题抽检；原始审计都保留，不能把定向难例的比例直接解释为总体错误率，也不能只检查容易题。结果需按任务、模型、提示词、布局和策略版本分层。

学生作答正确率按最终确认的题组统计，与历史累计正确率保持同一单位；明确确认留白可以按规则判错，未识别或待判定不能算错。逐空指标仅作模型诊断，不能替代题组正确率。低分提示继续暂缓；未来若展示采用前建议推算的结果，必须注明“暂估”，不能写入最终学情。

整题组正确率仍按现有业务处理，不用逐空评测值覆盖画像。组内其他空已错，也应保留未判定空的质量与处理状态。

## 5. 错误归因与人工反馈操作

标注顺序为：先不看标答核对原图与抄录，再以文本模型实际收到的题干及答案核对可接受性，最后检查最终判分与是否满足题目规则。可以分开人员或分开界面步骤，避免被标答诱导抄录。已有教师采用、画像变化或抄录修订不自动充当人工金标准。

| 场景 | 应记录的归因 |
| --- | --- |
| 图上为-1/7，模型抄为-1/2；等价模型正确处理了-1/2 | 识别错误，不因最后判错再给等价模型记一次错 |
| 识别忠实，但模型把两个明确不同的表达式判等价 | 等价错误 |
| 标答本身错误或遗漏条件 | reference_issue，先处理标答，不强行给模型贴错误标签 |
| 模型结束后教师另改学生答案 | input_changed，旧建议失效，不倒推旧模型错误 |
| 图片不足以确认原写法 | evidence_insufficient，保持uncertain，不默认正确或错误 |

最小反馈必须保存原输出、人工正确结果、核对者、时间、理由和反馈修订号。首次反馈、修正反馈及采用是不同动作；点击“保存质量核对”不能顺带改判或更新画像。

## 6. S0检查结果与后续验收

### 6.1 本次S0完成范围

- 两种模型请求字段白名单、三态等价结论、逐空视觉状态与反馈/采用状态已形成内部契约。
- 两页五槽位的合成样例涵盖三类模块、多空、选择字母E、判断符号、留白和歧义，示范原卷题号与展示排序不同仍按单元键对应。
- 阈值配置全部明确为未评测，真实调用与自动采用关闭；没有宣称已有真实质量数据。
- 多页实现采用冻结打印产物与页清单方向；v3仍待S3实现，未修改现有v2打印行为。
- 实际检查命令与结果另见[开发记录](01_S0契约与评测准备记录.md)。

### 6.2 进入S1的条件

本契约及样例足以开展内部持久化、fake、响应与版本校验、质量反馈接口开发。S1应将这里的协议落实为运行时校验并补齐负例测试，而不是把文档JSON读入后就当作输入已经合法。

### 6.3 后续真实验收仍待完成

- 选择实际供应商和版本，配置调用限额、费用记录及显式启动路径。
- 取得真实去身份化照片与人工金标准，完善独立验收集及数据保留要求。
- 处理首批能力范围、错误容忍、复核工作量和最小样本量；最终门槛在S6冻结。
- 完成多页产物、接口和完整业务链路，再评估自动采用。

阈值尚未确认或样本不足时，验收结论使用 `not_evaluated` 或“证据不足”，不生成通过结论。S0内部输入就绪与甲方业务验收、真实模型质量验收是不同完成状态。
