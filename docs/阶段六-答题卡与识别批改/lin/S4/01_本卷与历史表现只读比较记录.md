# S4-A：本卷与历史表现只读比较

日期：2026-11-25。

## 本轮范围

承接[历史累计正确率记录](../02_历史累计正确率与视觉识别后续口径记录.md)。用户本轮确认先实现可写代码的只读比较展示，为后续异常提醒提供统计依据。

批改页新增“本卷与历史表现参考”卡片，展示本卷已判定正确率、其他试卷历史正确率、本卷判定覆盖率及对应计数。无需新建独立试验页面，手工录入与图片抄录使用同一入口。

本轮没有设置最小样本量、0.6比较系数或异常阈值，没有新增整卷识别错误字段、告警、接受策略或自动采用。数据显示齐全只表示可以人工查看，不代表样本充分、质量通过或学生表现异常。

## 统计口径

| 项目 | 本轮口径 |
| --- | --- |
| 单位 | 一次题组作答；多空题仍按现有整组结果计一次，不按空数加权 |
| 本卷正确率 | 有效已判定答对题组数 / 有效已判定题组数 |
| 历史正确率 | 排除当前试卷实例后，其他试卷全部有效已确认作答的答对数 / 已确认数 |
| 判定覆盖率 | 本卷有效已判定题组数 / 发布试卷题组总数；待复核、未录入及无效记录均不补为答错 |
| 本卷计数 | 分别展示已判定、答对、答错、待复核、未录入及无效记录；未录入按发布题目中尚无当前学生作答的题组计数 |
| 历史有效性 | 复用画像当前证据校验；失效、未发布、归属错误、快照损坏、缺少当前修订等记录排除。确认的计算题和解答题继续纳入累计正确率，不扩大知识点掌握度或素养评分范围 |
| 修订与重复练习 | 每次作答只取当前修订；同题多次有效练习各计一次，同时展示不同题目数 |
| 零分母 | 返回null，显示“—”；已有确认记录且全错时显示0.0% |
| 知识点覆盖 | 按本卷冻结的主知识点，列出有/无其他试卷已确认作答及无法映射的题组数，并可展开逐知识点历史样本量；待复核和无效历史不构成已确认覆盖 |

本卷所有作答（包括待复核、无效记录）均从历史基准中排除，不直接使用画像页面包含本卷的累计百分比。历史采用查询时其他试卷的全部当前有效记录，也可能包含此卷之后完成的其他练习；不是按本次作答时间截断或事先冻结的基线。将来若做实时异常判定，需另行确定时间范围、基线冻结、最小样本量和知识点差异保护。

有已确认历史作答不代表掌握；没有这类记录也不代表从未学过。这里只核对主知识点，不将它替代完整的知识点覆盖或题目难度分析。

## 接口与实现

新增 `GET /api/v1/paper-instances/{paper_id}/accuracy-comparison`。不存在的试卷返回404；不依赖Stage6模型功能开关，不读取供应商配置或调用模型。服务复用 `load_context(..., include_literacy=False)` 与 `historical_accuracy` 的有效证据和计数逻辑；不持久化比较结果。

响应包含 `paper`、`history`、`knowledge_coverage`、`computed_at` 和只读标识；数据状态区分试卷未生效/失效、本卷无有效判定、无可用历史、本卷判定未完整及有可展示数据。`available`仅指展示数据存在，不是验收通过。

前端在原批改页题目统计下方显示卡片；答案提交、人工改判、撤销确认、重新评分或采用模型建议导致当前作答修订变化后，会重新读取统计。卡片也提供“刷新统计”，用于其他历史记录发生变化的情况。请求取消及过期响应不覆盖新状态，加载失败仅显示卡片内提示，不阻断原有批改。

| 文件 | 作用 |
| --- | --- |
| `backend/app/schemas/paper_accuracy.py` | 定义计数、覆盖及只读响应 |
| `backend/app/services/paper_accuracy.py` | 分离本卷/其他试卷证据并构造统计 |
| `backend/app/api/routes/submissions.py` | 新增只读统计接口 |
| `frontend/src/types/paperAccuracy.ts` | 前端响应类型 |
| `frontend/src/components/PaperAccuracyComparison.tsx` | 统计卡片、状态说明、刷新及知识点明细 |
| `frontend/src/pages/PaperGradingPage.tsx` | 接入原批改页 |

无需数据库迁移或新增环境变量，不修改既有作答、评分修订、画像和历史统计。不调用真实模型API。

## 后续边界

真实样本联调与独立质量验收继续按S5-C/S6推进。本功能不能据低分反推视觉模型错误，也不会把比较结果写成识别质量反馈。整卷错误标记、错误率接受阈值、低分告警及自动采用仍暂缓。
