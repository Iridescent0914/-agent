# S4-B：整卷识别质量人工核对记录

日期：2026-11-25。承接[S4-A只读表现参考](01_本卷与历史表现只读比较记录.md)，本轮由用户明确继续“按整份试卷记录识别核对结论”。

## 范围和使用

在原“答题页照片管理”的第5块“整卷答案核对与录入”下方，新增“整卷识别质量核对”。先合并整卷结果，再对照照片核对模型原始抄录，可在正式录入前或录入后登记。

1. 选择“未核对、确认无误、发现错误、无法判断”。
2. 填写本次质量核对人及至少2字说明；发现问题时写明实际误抄、漏抄或错位情况。
3. 新增确定结论时，须明确勾选已对照全部答题页照片、原始抄录及页码归属。
4. 保存后可查看对应逐页提取次数、模型及历史核对记录。刷新会保留已保存结论，清空本次操作人及说明，避免误用上次填写内容。

这项操作只登记模型抄录质量。修改学生答案、保存清单、确认录入、等价建议采用或人工改分，都不自动推导该结论；反过来，质量结论也不改学生答案、判分、确认状态或画像。

## 状态与版本

| review_status | 页面含义 | is_error |
| --- | --- | --- |
| pending | 未核对，可显式撤回为待核对 | null |
| correct | 人工确认本次整卷原始抄录无误 | false |
| incorrect | 人工发现本次整卷原始抄录有误 | true |
| uncertain | 无法给出确定质量结论 | null |

初次读取默认返回pending/null，不创建数据库记录；未核对不能充当“没有错误”。这里的“确认无误”不是学生全部答对，也不是质量验收通过或自动接受。

核对依据以整卷为单位，绑定试卷、打印产物、照片集合、每页图片哈希、任务ID/修订/提取次数、原始结果哈希及逐空原始抄录。一个多页整卷只保存一项整卷结论，不按页面或空数自动拆成错误率。

人工修正清单和题库标答内容不作为识别质量版本依据，因此修正答案或仅更新标答不会清空已有质量标签。冻结证据使用字段白名单，不复制标答、人工修正答案、供应商配置、Key或原始HTTP响应。

- 尚未录入时，补拍、重提或失效导致原合并结果不再对应当前提取，会阻止旧页面保存。重新合并后，新识别版本默认未核对，旧版本结论留在历史中，不自动沿用。
- 已录入时，核对对象固定为实际录入时使用的模型原始版本；后续有效照片切换不替换这一对象。面板明确说明核对对象，历史中的“当前”指此核对对象，不代表所有后来照片中的最新任务。
- 对应原照片不可用时，不能新增“确认无误/发现错误”。仍可操作的冻结版本（例如已录入版本）可登记未核对或无法判断；未提交且照片/提取已过期的版本须先处理版本问题。
- 模拟结果始终带模拟标志，仅供开发核对，不能计为真实质量验收或触发正式采用。

## 实现与事务

新增0042迁移：`paper_recognition_reviews`保存每个识别版本的冻结证据与当前状态，`paper_recognition_review_revisions`追加保存人工修订、操作人、说明及时间。数据库触发器保护冻结证据和不可覆盖历史。

接口沿用内部阶段六作用域：

```text
GET /api/v1/internal/stage6/paper-instances/{paper_id}/answer-card-artifacts/{artifact_id}/page-collection/recognition-review
PUT /api/v1/internal/stage6/paper-instances/{paper_id}/answer-card-artifacts/{artifact_id}/page-collection/recognition-review
```

PUT要求识别哈希及预期核对修订，服务端按照试卷、照片集合的既有锁顺序串行检查。旧版本和并发覆盖返回409；相同当前修订的完全相同内容重复保存不追加记录。每个集合最多1000条人工修订，历史接口最多显示最近100条。

该接口不调用模型、不创建识别任务、不重试供应商，不调用判分或画像服务。生产环境仍沿用内部入口禁用保护，填写的操作人文本仅用于内部审计，不代表已实现多教师身份认证。

主要文件：

- `backend/app/models/paper_recognition_review.py`、`backend/alembic/versions/0042_paper_recognition_reviews.py`：表与历史保护。
- `backend/app/schemas/paper_recognition_review.py`、`backend/app/services/paper_recognition_review.py`：严格输入、原始证据快照与独立保存。
- `backend/app/api/routes/assessment.py`：内部GET/PUT。
- `frontend/src/components/PaperRecognitionReviewPanel.tsx`、`frontend/src/types/paperRecognitionReview.ts`：质量面板和类型。
- `frontend/src/components/AnswerTranscriptionPanel.tsx`：接入原整卷页面，不新建试验入口。

本功能不设置错误率、比较系数、低分告警、接受阈值或自动采用，也尚未将整卷标签接入S5-C离线报告或增加质量汇总页面。后续评测不能把这些未经独立核对的使用记录直接当成验收真值。
