# S5-B：结合题干的答案可接受性判断

日期：2026-11-20。

## 需求变更与边界

用户发现“较小/小的”被判等价，而“较大/大”因缺少上下文返回无法确定，确认将后续任务从纯答案对比较调整为结合题干判断：学生答案放入目标空位，是否与标答表达相同的数学含义并满足题目要求。

此次明确替代S0及S5-A中“文本模型不接收题干”的旧限制；其他限制保持：不发送解析、其他空的标答或学生答案、学生身份、学情及教师操作标签。视觉模型仍只负责抄录学生原答，不接收标答。本轮未调用真实模型，未改已有成绩或画像，错误率统计、异常提示及自动采用继续暂缓。

## 发布快照与上下文定位

新增`answer_context.py`，仅从`PaperInstanceItem.question_snapshot.question_text`和冻结空位清单读取题干，不读取题库今日最新题干，也不将整个snapshot发送出去。snapshot可能含`solution/wrong_analysis`，此类字段不进入外发白名单。

- 小题编号、空号须与冻结结构对应，空号连续，题干下划线数量须匹配。明确分行且可独立处理时保留公共前缀和目标小题，将目标下划线替换为唯一的`【本空】`。
- 编号在同一行、存在跨小题引用或全局格式条件时，保守保留完整题组，并标记目标空位，避免裁掉条件。
- 唯一作答单元没有印出下划线时，保留完整题干并附“本题唯一作答位置：【本空】”。多空题不使用这一处理方式。
- 题干、编号或空位无法可靠对应时阻断候选，不猜空位，不降级为无题干判断。
- 本空上下文中有`[ASSET:...]`、图片引用或公式占位符，或题图存在但无法定位到具体文本时，提示人工复核。保留可读LaTeX；不自动读取题图、不触发额外视觉调用。题图明确属于另一独立小题且未进入所选上下文时，不影响本空。
- 原题干限制24000字符，外发上下文限制12000字符；超限阻断，不截断重要条件。

保存上下文版本、实际外发内容哈希、完整来源题干/资源/空位结构哈希。创建、领取、完成及采用均继续检查冻结输入；来源变化或外发上下文与快照不符时，任务失效。整卷预检摘要也加入发布题干和资源。

## V2协议及判断口径

新任务使用`stage6-equivalence-request-v2`：

```json
{
  "schema_version": "stage6-equivalence-request-v2",
  "request_id": "00000000-0000-4000-8000-000000000001",
  "reference_answer": "较大",
  "student_answer": "大",
  "answer_context": {
    "scope": "question_group",
    "question_text": "从两个数中选择一个，用词语描述所选的数：【本空】。",
    "target_subquestion_no": 1,
    "target_blank_no": 1
  }
}
```

上下文由后端构造；前端创建请求仍只传题项、空位及预期版本，不能自行提交题干绕过快照。调用传输严格校验V2白名单，继续使用当前百炼模型、累计费用预占及次数限制。

响应使用`stage6-equivalence-response-v2`。内部保留三态字段以复用评分接口，但按协议版本区分含义：

| verdict | V2含义 | reason_code |
| --- | --- | --- |
| equivalent | 本空可接受 | contextual_match |
| not_equivalent | 本空不可接受 | contextual_mismatch |
| uncertain | 无法确定 | context_required / context_incomplete / reference_issue / unparseable_answer / unsupported_answer |

提示词版本为`stage6-contextual-bailian-v2`，采用策略为`stage6-contextual-candidates-v3`。允许不改变数学含义的口语和语法成分增减；“较大/大”“较小/小的”使用对称标准，实际题干明确比较关系且含义不变时可接受。不得把它们登记成无条件同义词，也不得自行补比较语境。

正负、严格/非严格关系、数量、单位、顺序、定义域及最简形式等限定仍须保留。“负/非正”“大于/大于等于”不能仅因词语相近而判可接受。标答疑似矛盾返回`uncertain/reference_issue`并阻断采用，不让模型改标答或重新生成答案。

旧V1请求/响应保留严格解析以读取历史和质量反馈；新真实HTTP仅接收V2，不隐式切回V1。旧任务不作为当前任务复用，未改写原请求和原结果。仍会计入数据库累计调用及费用。

## 前端、采用与使用方法

沿用原“整卷等价判断”及逐题侧栏入口。新增“查看本空题干与位置”，展示实际使用的上下文；V2结果显示“本空可接受/本空不可接受/无法确定”。旧侧栏记录标为“旧版记录：仅比较答案”，保留原“等价/不等价”的历史含义。

采用仍要求该题所有候选具有确定、有效、真实且未经质量反馈否定的结果。采用记录升级为`stage6-contextual-teacher-adoption-v2`，保存context哈希；原答、规则结果、其他空判定、修订幂等与画像同事务刷新均保持。题干或标答存在问题时使用原人工复核与题库审核入口。

用户可直接对已核对录入的作业操作：刷新批改页 → 检查或刷新整卷 → 展开核对题干和本空 → 明确发起新版判断 → 逐题核对并采用。无需重拍、重新视觉提取或重新录入。版本升级后，旧答案对结果不能代替带题干的新结果；显式发起新版任务会正常计费，普通检查不会调用模型。

本轮不增加迁移、不修改`.env`或API Key，不调整次数与费用上限；沿用0037及现有JSONB证据字段。

### 逐空采用记录展示补充（2026-11-20）

已保存的逐空采用证据此前未在批改页直接展示，教师难以区分哪些空仍使用规则结果、哪些空已经采用模型建议。本次在每题学生答案上方和整卷判断侧栏增加“答案建议采用记录”，列出具体小题/空号、已采用的可接受性结论、评分修订、核对人及采用原因。无需重新检查整卷或调用模型，刷新页面也能看到。

显示直接读取评分证据`grading_details.equivalence_review.decisions`，不把仅已生成、未采用或模拟建议标为已采用。一个题组中未采用建议的其他空不加入记录；采用“本空不可接受”也明确显示，不能将“采用建议”理解为“判为正确”。按标准空位ID或参考答案中的坐标定位，并按小题、空号排序，避免按采用顺序猜测空号。旧版答案对采用记录保留“等价/不等价”的含义。

仅`applied_revision_no`与当前评分修订一致时标为“已采用建议”；后续人工复核产生新修订、但仍保留原证据时，改标为“历史采用记录”，提示以最新评分为准。修正原答或重新评分若已替换当前证据，原采用证据仍可通过原有修订历史查看。本次只补展示，不修改评分、画像、模型调用或数据库结构。

补充验证：前端生产构建通过；S5桌面/手机浏览器16项通过，覆盖采用后即时展示及刷新保留、非连续小题/空号、正反结论、规则判分空不误标、未采用/模拟结果不误标、后续修订显示历史记录。测试初次因关闭按钮使用英文定位失败，改用界面的中文“关闭”后全部通过。实际5173服务曾缓存旧模块，重启前端后只读确认指定试卷第3题4个空的采用记录及侧栏均正确展示，3个可接受、1个不可接受；检查禁止所有写请求，未发起任何模型调用。未提交或push。
