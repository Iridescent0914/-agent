# 题库教师审核与动态组卷池补充完善

> 完成日期：2026-09-27  
> 对应阶段：M3 补充完善  
> 适用范围：题库展示层、自动组卷池、选择题和填空题

## 1. 补充背景

M3 已将题库拆分为“完整题库展示层”和“自动组卷池”：完整题库 139 组，初始自动组卷池 41 组，初始待入库验证 98 组。计算题、解答题等复杂题型保留在展示层，只有答案结构可靠的题目参与自动推荐和组卷。

本轮补充解决以下问题：

1. 题库需要按题型和题库状态筛选；
2. 待入库选择题、填空题需要允许教师核对和修改答案；
3. 数学答案可能包含分数、根式等公式；
4. 教师确认后的题目需要进入自动组卷池；
5. 已入池题目需要支持撤回、修改和重新入池；
6. 自动组卷池数量会动态变化，测试和验收不能继续写死为 41 题。

## 2. 最终业务流程

### 2.1 待入库题目

当前只开放选择题和填空题的人工审核：

1. 教师按“题型”和“题库状态”筛选；
2. 点击题库列表右侧的“去审核”；
3. 在详情页点击“审核答案并进入组卷池”；
4. 编辑每个答案项及判分方式；
5. 可先保存审核草稿；
6. 校验通过后明确确认进入自动组卷池。

保存草稿不会让题目参与组卷，只有“校验并确认入池”才改变题库状态。

### 2.2 已入池题目

已入池的选择题和填空题提供“撤回/编辑”入口：

1. 教师在列表点击“撤回/编辑”；
2. 在详情页点击“撤回并重新编辑”；
3. 填写操作人，可选填撤回原因；
4. 确认撤回到待审核状态；
5. 撤回成功后，同一个抽屉立即切换为答案编辑界面；
6. 修改完成后重新校验并再次入池。

撤回只影响后续自动推荐和组卷。已经生成或发布的试卷继续使用原有快照，不会被当前题库变化回改。

## 3. 答案输入与公式处理

### 3.1 选择题

- 每个答案项使用 A-H 选项选择器；
- 后端拒绝空答案、多字符答案和非选项答案；
- 判分方式固定为 **choice**。

### 3.2 填空题

| 判分方式 | 适用答案 | 当前校验 |
| --- | --- | --- |
| **numeric** | 整数、小数 | 后端校验标准数值格式 |
| **exact** | 普通文字、符号或固定表达 | 去除首尾空白后精确匹配 |
| **latex_exact** | 分数、根式等数学公式 | 保存并精确匹配 LaTeX 源码 |

公式输入使用 MathLive 可视化数学编辑器。教师看到排版后的数学公式，系统保存 LaTeX 源码，不保存公式截图。

当前阶段不承诺代数等价判定。例如二分之一、小数 0.5 和对应 LaTeX 分式不会自动视为同一种答案。复杂符号等价和代数化简可在后续阶段接入专门的数学表达式判定能力。

## 4. 状态、版本和审计

题目审核新增：

- **review_revision**：审核版本号；
- **review_history**：审核事件；
- **reviewed_by**：最近操作人；
- **reviewed_at**：最近操作时间。

审核事件包括：

- **draft_saved**：保存审核草稿；
- **promoted**：确认进入自动组卷池；
- **withdrawn**：撤回到待审核状态。

每次写操作都要求提交 **expected_review_revision**。如果题目已被其他教师修改，后端返回 409，提示刷新后重新操作，避免多人审核时互相覆盖。

教师审核结果属于业务数据。以后再次执行 **seed_database** 时，可以刷新来源题干和元数据，但不会覆盖已审核的结构化答案、判分规则、入池状态、审核历史和版本。

## 5. API 补充

- **PUT /api/v1/questions/{question_id}/review-draft**：保存审核草稿，继续保持待入库状态；
- **POST /api/v1/questions/{question_id}/promote**：校验通过后进入自动组卷池；
- **POST /api/v1/questions/{question_id}/withdraw**：撤回到待审核状态并写入审计。
- **POST /api/v1/questions**：教师手动录入新题，初始进入待审核区。
- **DELETE /api/v1/questions/{question_id}**：业务删除题目，不影响既有试卷快照与作答。

## 6. 前端补充

题库列表新增固定“操作”列：

- 待入库选择题/填空题显示“去审核”；
- 已入池选择题/填空题显示“撤回/编辑”；
- 当前未开放审核的复杂题型显示“查看”。
- 页面右上角提供“上传新题”，每行提供“删除”操作。

题目详情页新增醒目的独立操作区：

- 待入库状态显示“审核答案并进入组卷池”；
- 已入池状态显示“撤回并重新编辑”；
- 桌面端和 390px 移动端均可正常操作；
- 公式编辑器按需加载，避免普通题库页面首屏加载完整数学引擎。

## 7. 数据库迁移

新增迁移文件：

**backend/alembic/versions/0007_add_question_review_workflow.py**

题目审核功能对应迁移为 **0007**，它为 **questions** 表增加审核版本、审核历史、操作人和操作时间，并约束审核版本必须大于等于 1。**0010** 为题目和学生增加业务归档字段，使删除不破坏历史快照和作答。当前项目 head 为 **0010**。

## 8. 动态题量验收调整

教师可以执行确认入池和撤回，因此自动组卷池与待入库题量不再是固定常量。

验收现在检查：

- 题库总数仍为 139；
- **ready_count + pending_count = total**；
- 每道题只有合法的题库状态；
- 自动组卷只使用 **machine_ready** 且来源已审核的题目；
- 教师操作不会破坏学生、作答、画像和试卷数据。

截至本文记录时，数据库实际状态为：

- 自动组卷池：42 组；
- 待入库验证：97 组；
- **q.math.g6.rational.school.050** 已由“任课教师”完成草稿保存和确认入池；
