# 新版有理数题库字段与知识点调整记录

## 1. 变更背景

本次以 `六年级_数学_校本审核/新/rational_有理数.docx` 为新的权威来源，按稳定的题目 ID 更新现有有理数题库。旧版 Word 中的“主属考点/关联考点”不再作为题目知识标签，改用新版 Word 的“主属节—节内主属 KP”层级。

新版 Word 共 139 道题，每道题都提供以下字段：

| 新版 Word 字段 | 系统落库/数据字段 | 说明 |
| --- | --- | --- |
| 题目 ID | `original_qid` | 作为幂等更新键，不新增重复题 |
| 题型 | `question_type` | 保持现有英文枚举 |
| 难度 | `difficulty` | 星级转换为 1–5 整数 |
| 年级 | `grade` | 新增数据库字段 |
| 章 | `chapter_code`、`chapter_name` | 本批为 `math.g6.rational` / `第1章 有理数` |
| 主属节 | `questions.section` | 题库列表、详情和筛选直接使用该字段 |
| 节内主属 KP | `questions.main_knowledge_point_id` / API `main_knowledge_point` | 指向正式 `math.g6.rational.kp.*` 知识点，不再来自旧考点 |
| 核心素养 | `core_literacy` | 新增数据库字段，保留源文多值文本 |
| 是否为必做题 | `is_required` | 新增布尔字段 |

知识点自身的 `mastery_level`、`core_competencies`、`curriculum_basis` 来自上海五四制知识图谱；题目的 `core_literacy` 来自新版 Word。既有 `ExamPoint` 继续作为画像、推荐和组卷的一对一 `tracking.*` 内部统计键，不作为旧考点展示。

## 3. 代码与数据库调整

### 3.1 数据构建

`scripts/build_rational_m0.py` 已改为：

1. 默认优先读取 `六年级_数学_校本审核/新/rational_有理数.docx`；
2. 严格解析新版九项元数据；
3. 逐题保留 Word 的“主属节”，将“节内主属 KP”映射到正式知识图谱节点；
4. 校验节和 KP 名称必须在正式知识图谱中，并使用稳定的 `sec.*`、`kp.*` 和内部 `tracking.*` ID；
5. 对“是否为必做题”只接受“是/否”，异常值会直接终止构建；
6. 输出 schema version 2.0 的题库、知识树和审计报告。

`scripts/validate_m0.py` 会检查完整 139 道题，而不只检查种子题，确保每题均有题目 ID、题型、难度、年级、章、主属节、节内主属 KP、核心素养和布尔型必做题标记。

### 3.2 持久化与 API

迁移链已修正为：

- `0020_add_knowledge_graph_metadata.py`：为 `knowledge_points` 增加 `mastery_level`、`core_competencies`、`curriculum_basis`；
- `0021_add_question_curriculum_metadata.py`：为 `questions` 增加以下字段：

- `grade varchar(80) not null`
- `core_literacy varchar(255) not null`
- `is_required boolean not null`

原先题目字段误用了数据库中已经存在的 `0020` 版本号，导致数据库显示已到 `0020`、但题目列没有创建。本次已消除版本冲突并实际升级到 `0021`。

种子导入器按 `original_qid` 幂等更新题目，因此重导后仍是 139 道，不会因更换知识标签而产生重复题。题目列表和详情 API 已返回三个新字段；教师新增、编辑题目时也可以维护这三个字段。

知识目录接口只展示仍被当前未归档题目引用的节点，旧版考点即使作为历史兼容数据仍存在数据库中，也不会再出现在题库、选题和学情目录里。

已发布试卷快照保持不可变。若历史作答快照仍保存旧 `exam.local.*` 代码，学情重放和作答筛选会根据稳定题目 ID 映射到当前 `tracking.*` 节点；详情仍保留发布时原始快照。

### 3.3 前端

- 题库列表新增年级、主属节、节内主属 KP、核心素养、必做题列。
- 题目详情展示新版全部元数据，并用红色标签突出必做题。
- 上传新题、编辑题目表单新增年级、核心素养、必做题字段。
- 当前界面中的“考点”文案统一改为“知识点”；内部 `exam_point_*` 名称暂时保留以兼容既有接口和算法。
- 题库筛选改为直接按章、`Question.section` 主属节和正式知识点筛选。
- 修正了把集合名或数轴点名 `A、B、C` 误识别为选择项的问题；支持判断题进入组卷、作答、自动判分和教师审核流程。
- 人工核对并结构化第 16 题（多空填空）和第 50 题（两小题选择）；第 97、122 题的判断答案由 Word 原文稳定解析。

## 4. 部署与重导步骤

在 Docker Desktop 已启动的情况下，于 `code` 目录执行：

```powershell
docker compose up -d postgres
docker compose run --rm backend alembic upgrade head
docker compose run --rm backend python -m scripts.seed_database
```

若后端容器已经运行，执行：

```powershell
docker compose exec backend alembic upgrade head
docker compose exec backend python -m scripts.seed_database
```

导入后建议再执行项目既有的掌握度重建命令：

```powershell
docker compose exec backend python -m scripts.rebuild_mastery --all
```

`rebuild_mastery` 必须提供 `--all` 或 `--student-code`，不能无参数执行。
