# 旧考点兼容层彻底移除与知识点全链路重构记录

## 1. 最终结论

本次没有继续保留 `ExamPoint` 兼容层。系统当前只存在一套知识分类：新版校本审核 Word 的“节内主属 KP”，在代码和数据库中统一表示为 `KnowledgePoint` 与 `knowledge_point_*`。

旧 Word 抽取出的考点、`exam.local.*` ID、为兼容代码建立的 `tracking.*` ID，均不再参与题库、学生画像、班级学情、推荐组卷、试卷快照或接口传输。当前数据库中也不再存在 `exam_points`、`question_exam_points` 两张表。

说明：`0001`、`0002`、`0003`、`0006`、`0022` 等旧 Alembic 文件属于已执行过的数据库迁移历史，必须保留，才能让旧数据库按顺序升级；它们不代表当前数据库仍有旧表。最终结构由 `0023_remove_exam_point_compatibility.py` 确定。

## 2. 统一后的数据模型

### 2.1 题目

每道题直接通过 `questions.main_knowledge_point_id` 关联 `knowledge_points.id`。题目业务字段为：

- 题目 ID：`original_qid`
- 题型：`question_type`
- 难度：`difficulty`
- 年级：`grade`
- 章：`chapter_code`、`chapter_name`
- 主属节：`section`
- 节内主属 KP：`main_knowledge_point_id`
- 核心素养：`core_literacy`
- 是否为必做题：`is_required`

题目不再维护“主考点”“关联考点”或额外的一对一跟踪节点。

### 2.2 学生画像与班级学情

`student_masteries` 的联合主键改为：

```text
(student_id, knowledge_point_id)
```

掌握度重放、薄弱点、最近错题、学生历史筛选、班级知识点统计和学生下钻全部直接使用正式知识点代码 `math.g6.rational.kp.*`。历史作答通过稳定的 `question_id` 解析题目当前主知识点，不再执行旧考点别名映射。

### 2.3 推荐、组卷与试卷快照

推荐请求统一使用：

```text
new_knowledge_point_codes
review_knowledge_point_codes
max_knowledge_point_ratio
```

推荐结果与诊断统一使用：

```text
knowledge_point_code
knowledge_point_name
knowledge_point_codes
capped_knowledge_point_codes
max_per_knowledge_point
selected_per_knowledge_point
```

`paper_instance_items.knowledge_point_snapshot` 使用直接结构：

```json
{
  "id": "math.g6.rational.kp.07_add_subtract",
  "name": "有理数的加法法则与减法法则"
}
```

不再使用原来的 `exam_point_snapshot.main/related` 嵌套结构。

## 3. 数据库迁移 0023

迁移文件：`backend/alembic/versions/0023_remove_exam_point_compatibility.py`

迁移执行了以下操作：

1. 将 `student_masteries.exam_point_id` 转换为直接外键 `knowledge_point_id`；同一学生若有多个旧子考点落到同一正式知识点，保留更新时间最新的一条物化结果，后续可由作答证据重放得到确定结果。
2. 临时停用已发布试卷不可变触发器，把草稿和已发布试卷的全部知识点快照转换为题目当前正式知识点，并把列名改为 `knowledge_point_snapshot`，随后恢复触发器。
3. 递归迁移作业教学范围、生成配置、推荐审计、编辑记录、选题审计及题目审核记录中的字段名和知识点 ID。
4. 把 `exam_point_cap`、`missing_main_exam_point` 等旧原因码改为知识点命名。
5. 删除 `question_exam_points` 和 `exam_points` 表。
6. 删除仅用于承载旧 Word 考点的无题目父节点 `math.g6.rational.add_sub`。

## 5. 后端与接口调整

- 删除 ORM 模型 `ExamPoint`、`QuestionExamPoint` 及其关系。
- 题库新增、编辑、详情、筛选和目录直接读取 `KnowledgePoint`。
- 学生画像、掌握度历史、最近错题和作答详情统一返回 `knowledge_point_*`。
- 班级学情及知识点学生下钻接口改为 `/analytics/classes/knowledge-points/{knowledge_point_code}/students`。
- 知识点目录接口改为 `/knowledge-points`。
- 推荐、作业、试卷版本、替换题、发布、提交和批改工作流统一使用直接知识点字段和快照。
- 种子导入器不再创建旧表记录或题目—考点关联。

## 6. 前端调整

- 删除 `ExamPoint` 类型，统一为 `KnowledgePoint`。
- `ClassExamPointChart`、`ExamPointStudentDrawer` 分别重命名为 `ClassKnowledgePointChart`、`KnowledgePointStudentDrawer`。
- 题库新增/编辑表单取消“关联考点”字段，只维护一个节内主属 KP。
- 学生画像、班级学情、推荐预览、作答历史、试卷编辑和批改页面全部使用 `knowledge_point_*`。
- 试卷页面直接读取 `knowledge_point_snapshot.name`，不再读取 `.main.name`。
- 前端生产构建通过。

```powershell

docker compose exec backend alembic upgrade head
docker compose exec backend python -m scripts.seed_database
docker compose exec backend python -m scripts.rebuild_mastery --all
docker compose exec backend pytest -q
docker compose exec backend python -m scripts.verify_m1
docker compose exec backend python -m scripts.verify_m2
```
