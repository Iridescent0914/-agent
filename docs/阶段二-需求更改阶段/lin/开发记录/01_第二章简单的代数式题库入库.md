## 2. 权威来源与字段

新版 Word 逐题提供以下字段，均直接作为题库字段来源：

- 题目 ID；
- 题型；
- 难度；
- 年级；
- 章；
- 主属节；
- 节内主属 KP（主要知识点）；
- 核心素养；
- 是否为必做题；
- 题干、参考答案、解析、易错分析和资源关系。

题目稳定 ID 使用 Word 中的 `original_qid`，格式为：

```text
q.math.g6.expr.school.001
...
q.math.g6.expr.school.041
```

第二章正式章节 ID：

```text
math.g6.expr
```

知识点 ID 统一使用：

```text
math.g6.expr.kp.<stable_suffix>
```

不再使用旧的 ExamPoint 兼容字段。

## 4. 生成和修改的文件

  - 保留第一章默认行为；

### 4.3 后端导入脚本

修改 `backend/app/services/seed_importer.py`：

- 种子题数量范围由固定 30～50 改为可配置；
- 完整题库数量由固定 139 改为可配置；
