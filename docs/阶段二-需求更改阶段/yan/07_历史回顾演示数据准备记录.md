# 历史回顾演示数据准备记录

> 日期：2026-10-27  
> 范围：为历史回顾组卷准备可重复使用的已完成作业数据

## 1. 背景

创建作业页的历史回顾下拉框只显示当前班级最近五次“全部批改完成”的作业。原有 M1 历史种子生成时间早于新版三模块组卷合同，其试卷题目没有 `source_module = required` 选择审计，不能作为新版历史回顾错题来源。

因此新增独立、幂等的历史回顾演示数据准备脚本，不修改或删除原有作业。

## 2. 演示数据

默认向“六年级 Demo 班”准备两份作业：

```text
历史回顾测试：已批改必做题 1
历史回顾测试：已批改必做题 2
```

每份作业满足：

- 班级内每名在读学生各有一份已发布试卷；
- 每道题均来自 `is_required = true`、已审核且可机判的三星及以下题目；
- 每道题的选择审计均记录 `source_module = required`；
- 所有学生均已提交并形成最终判定，不包含草稿、未提交或待复核状态；
- 不同学生分别设置 0、1 或 2 道错题，用于验证逐学生历史题差异；
- 每道来源题所在的“知识点 + 难度”至少保留另一道可用题，便于验证同知识点、同难度替换；
- 使用稳定 `seed_key`，重复执行不会重复创建。

## 3. 使用方式

数据库启动并完成题库种子导入后，在 `code/backend` 目录执行：

```powershell
$env:DATABASE_URL = "postgresql+psycopg://postgres@localhost:55432/math_agent"
& "..\.conda-env\python.exe" -m scripts.prepare_history_demo
```

然后进入“创建班级作业”：

1. 班级选择“六年级 Demo 班”；
2. 展开“历史回顾”；
3. 从最近已批改作业中选择上述任一作业；
4. 完成其他必填筛选并预检；
5. 检查不同学生的历史回顾题数量是否随错题数量变化。

脚本支持指定其他班级或种子前缀：

```powershell
python -m scripts.prepare_history_demo --class-name "班级名称" --seed-prefix "自定义稳定前缀"
```

## 4. 代码与验证

- `backend/app/services/history_demo.py`：构造题目、发布试卷、提交答案并校验全部批改状态；
- `backend/scripts/prepare_history_demo.py`：命令行入口；
- `backend/tests/test_history_demo.py`：验证全部批改、存在有错/无错学生、能够读取历史错题以及重复执行幂等。

本功能只准备演示数据，不改变历史回顾选题规则，也不实现个性化或周总结逻辑。
