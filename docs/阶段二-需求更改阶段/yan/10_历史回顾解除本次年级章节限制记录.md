# 历史回顾解除本次年级章节限制记录

> 日期：2026-10-27  
> 负责人：yan  
> 范围：历史回顾候选池与草稿换题范围  
> 不包含：必做题筛选、个性化后端组卷、连续错题标签和周总结

## 1. 需求调整

历史回顾来源由教师从当前班级最近五次有效已批改作业中明确选择，因此不再使用本次组卷表单的年级和章节限制历史题。

调整后的模块边界是：

```text
本次年级、章节
├─ 限制必做题
├─ 限制个性化题（后续实现）
└─ 不限制历史回顾题

历史回顾来源作业
└─ 来源必做错题的知识点 + 难度
   └─ 决定历史替换题候选池
```

教师可以在本次教授其他年级或章节内容时，主动选择一份不同范围的历史作业进行回顾。

## 2. 原有问题

此前历史候选题通过以下参数加载：

```text
filter_config.grade_codes
filter_config.chapter_codes
```

即使来源作业存在有效的一至三星必做错题，只要该错题不属于本次所选年级或章节，候选池就会变为空，并返回历史题库存不足。

这与“来源作业由教师明确选择”的业务语义重复约束，也会造成教师已经选择来源作业但历史回顾仍为 0 的误解。

草稿中的历史题换题也存在相同限制：换题候选会再次套用本次年级和章节范围。

## 3. 后端组卷修复

新增独立的历史候选加载函数：

```text
history_recommendation_candidates
```

加载步骤调整为：

1. 读取教师选定来源作业中各学生的一至三星必做错题；
2. 汇总这些错题的知识点代码；
3. 直接按知识点代码加载未归档题目；
4. 在逐题选择阶段继续严格匹配来源错题的知识点与难度。

历史候选加载不再接收本次 `grade_codes` 或 `chapter_codes`。

必做题候选池仍完整使用本次年级、章节、知识点、核心素养与难度数量配置，没有受到本次调整影响。

## 4. 历史题换题修复

草稿中的历史题换题同样解除本次年级和章节限制，候选必须满足：

- 与来源错题知识点相同；
- 与来源错题难度相同；
- 已审核、可机器判分且未归档；
- 不是来源错题；
- 不是当前试卷中已有题目。

换题仍保留来源 Attempt、修订号、`source_module = history` 和历史原因码。

## 5. 示例

假设教师本次筛选：

```text
年级：七年级上册
章节：整式
```

同时选择的历史来源作业中，某学生有一道：

```text
六年级上册 / 有理数 / 数轴 / 三星 / 必做错题
```

系统仍会为该学生生成一道“数轴、三星”的历史替换题。七年级和整式范围只用于本次必做题与以后接入的个性化题。

## 7. 验收标准

```text
□ 本次年级和章节仍能正确限制必做题。
□ 历史来源作业可以属于与本次筛选不同的年级或章节。
□ 跨范围来源错题仍能生成同知识点、同难度历史题。
□ 历史替换题不与来源错题或当前试卷已有题目重复。
□ 跨范围历史题在草稿中仍能获取合规换题候选。
□ 预检与正式生成结果一致。
```
