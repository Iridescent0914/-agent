# 历史回顾排除来源整卷重复题修复记录

> 完成日期：2026-10-29
> 范围：历史回顾自动组卷、草稿换题候选和阶段二验收合同
> 不包含：个性化后端组卷、连续错题标签和周总结

## 1. 业务规则

历史回顾替换题必须与来源错题属于同一知识点、同一难度，同时满足以下去重规则：

1. 不得与该学生在教师所选来源作业整张有效试卷中的任何题目重复；
2. 不得与当天必做题重复；
3. 个性化组卷接入后，不得与当天个性化题重复；
4. 不得与该学生当天已经选中的其他历史题重复。

来源作业的“整张有效试卷”指该学生在来源作业中当前未失效的 published `PaperInstance` 及其全部 `PaperInstanceItem`，不限于答错题或必做题。

## 2. 原有缺陷

原实现只把以下题目加入历史候选排除集合：

- 当天必做题；
- 来源作业中符合历史回顾条件的一至三星必做错题。

因此，当来源作业中存在另一道同知识点、同难度且学生答对的题时，该题仍可能被选为历史替换题。首次生成后的教师草稿换题候选也只排除了来源错题，没有排除来源整卷。

## 3. 实现调整

`recommendations.py` 新增 `history_source_question_ids`，按学生读取所选来源作业当前有效发布试卷的全部题目 ID。

`paper_generation.py` 在逐学生生成历史题时，将以下集合合并后传给历史选择器：

```text
当天已选必做题 ID
∪ 该学生来源作业整张有效试卷题目 ID
```

历史选择器内部继续使用 `used` 集合，避免同一学生的多道历史题互相重复。个性化后端组卷接入时，应先生成个性化题，再把个性化题 ID 合并到同一个排除集合中。

`paper_workflow.py` 的历史题草稿换题候选会从当前作业的 `generation_config.filter_config.history.assignment_id` 找到来源作业，并排除该学生来源整卷的全部题目。旧草稿缺少阶段二配置时，继续使用历史证据中的 Attempt 题目作为兼容排除规则。

## 4. 回归覆盖

后端工作流测试构造同一来源试卷中的三道同知识点、同难度题，其中只有第一道答错。测试同时验证：

- 自动生成的历史替换题不属于来源整卷；
- 教师打开历史题换题候选时，来源整卷三道题全部不出现；
- 历史题仍保持来源证据、知识点、难度和 `source_module = history` 审计。

## 5. 最终边界

当前当天题目只有必做题和历史题，个性化模块仍只保存配置。因此本次已经实际完成“来源整卷 + 当天必做题 + 其他历史题”去重；“当天个性化题”将在个性化后端组卷接入时并入同一排除集合，不能另建一套去重口径。
