# 创建作业默认配置、错误提示与界面精简记录

日期：2026-10-28

## 问题

教师进入创建作业页后，直接沿用系统默认的作业标题、班级、年级、章节和必做题配置，不选择个性化与历史回顾，点击“预检全部学生”时，页面显示：

```text
操作失败
请先完成作业标题、班级、年级和章节选择
```

该提示与实际缺失项不一致。作业标题、班级、年级、章节和必做题已经有默认配置，当前真正缺少的是必选的个性化知识点和主要能力；历史回顾本身允许不选择。

## 原因

创建作业表单中的个性化知识点和主要能力配置了字段级必填规则。教师未配置个性化模块时，Ant Design Form 会先进入 `onFinishFailed`，不会执行预检回调中的业务校验。

原来的 `onFinishFailed` 无论哪个字段校验失败，都会固定显示“请先完成作业标题、班级、年级和章节选择”，因此把个性化配置缺失错误归因到了基本信息。

## 修复内容

### 1. 按实际表单状态生成错误原因

表单校验失败后，重新读取完整 Form Store，并复用创建作业页的业务校验顺序。当前前端会区分：

- 未填写作业标题：`请填写作业标题`；
- 未选择班级：`请选择班级`；
- 未选择年级或章节：`请选择至少一个年级和章节`；
- 必做题总数为 0：`请设置至少 1 道必做题`；
- 未选择个性化知识点：`请选择个性化模块的知识点`；
- 已选择个性化知识点但未选择主要能力：`请选择所选知识点对应的主要能力`；
- 已选择的历史作业失效：`历史回顾作业无效，请重新选择`。

只有无法归类的字段校验失败才使用兜底提示“请检查表单中的必填项”。

### 2. 自动定位到个性化配置

如果实际错误是个性化知识点或主要能力未配置，页面会自动展开“个性化筛选”面板，让教师可以直接完成缺失配置。

如果实际缺少的是标题、班级、年级、章节或必做题数量，则不强制切换到个性化面板。

### 3. 默认配置与可选边界保持不变

本次修复不改变原有默认值和业务规则：

- 作业标题默认是“数学作业”；
- 班级默认选择第一个有在读学生的班级；
- 年级默认选择“全部年级”；
- 章节默认选择“全部章节”；
- 必做题默认配置为 6 道二星题；
- 必做题知识点和核心素养允许不选择；
- 个性化知识点和主要能力必须配置，但本阶段只保存配置，不生成个性化题；
- 历史回顾允许不选择。

## 组卷页面精简

### 调整目标

创建作业页顶部和题目模块标题区原本重复展示了较多流程说明与统计信息。本轮只保留页面标题和实际配置表单，不改变默认值、筛选合同、预检或正式生成逻辑。

### 删除内容

页面不再显示：

- “智能组卷工作台”标签；
- “确定教学范围，组合全班必做题与逐学生历史回顾；预检确认后再生成草稿。”说明；
- “预检不写入数据库 / 必做题全班统一 / 历史回顾逐学生生成”三条说明；
- “当前必做题 6 道 · 按难度配置”统计卡；
- “点击卡片展开设置；必做题与历史回顾会进入本轮试卷”副文案。

同时删除上述顶部说明区对应的未使用 CSS，避免保留失效样式。

页面继续保留：

- “创建班级作业”页面标题；
- 作业基本信息和学生范围；
- 必做题、个性化、历史回顾三个配置入口；
- 各星级必做题数量和动态必做题总数；
- 预检、错误提示、预检结果和生成草稿操作。

本轮没有实现或调整“智能作业系统素养动态评分与个性化出题机制”算法。个性化模块仍只保存筛选配置，后端真实个性化组卷后续另行开发。

## 测试

- `npm run typecheck`：通过。
- `npm run build`：通过。
- 创建作业页定向 Playwright 回归：默认配置与错误提示、页面精简与窄屏布局两组用例在 desktop、mobile 共 `4 passed`。
- 回归用例确认：
  - 默认标题、班级、全部年级、全部章节和默认必做题可直接沿用；
  - 未配置个性化时显示“请选择个性化模块的知识点”；
  - 页面自动展开个性化筛选面板；
  - 错误提示仍位于预检操作区正下方；
  - 完成个性化配置后，预检请求继续使用展开后的真实年级、章节、知识点及当前班级范围。
  - 已删除的顶部说明、必做题统计卡和题目模块副文案不再渲染；
  - 页面精简后桌面端和移动端没有产生横向溢出。

完整 M3 浏览器用例曾使用临时前端端口 `5174` 运行，其中依赖真实后端的用例被后端仅允许 `5173` 的 CORS 配置阻止并显示 `Failed to fetch`；完全模拟接口的本次目标回归通过，该环境失败与本次修复无关。

## 当前结论

教师可以直接沿用基本信息和必做题默认配置。个性化未配置时，系统会准确提示缺少个性化知识点或主要能力，并自动定位到对应面板；不再错误提示教师重新选择已经存在默认值的作业标题、班级、年级和章节。创建作业页同时移除了重复的顶部说明、统计卡和模块副文案，保留实际配置与操作区域。
