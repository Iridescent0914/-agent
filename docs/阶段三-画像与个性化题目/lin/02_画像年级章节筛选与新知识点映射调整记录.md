# 画像与班级学情：年级筛选及新知识点映射调整记录

> 记录日期：2026-10-29  
> 范围：阶段三基础画像展示，不新增素养算法或素养结果数据库结构。

## 1. 本次需求

1. 班级学情中的知识点显示改用阶段二正式知识点目录。目录遵循上海市五四制初中数学知识图谱的“章—节—知识点”关系，不再把旧考点名称作为展示分类。
2. 学生学情、班级学情的筛选增加“年级”一级条件；选择年级后，章节选项只显示该年级下的章节。

## 2. 映射口径

- 章和知识点的正式标识来自 `KnowledgePoint.chapter_code`、`KnowledgePoint.code`，当前种子数据使用 `math.g*.{chapter}.kp.*` 形式的阶段二知识点编码。
- 节的展示名称以题目的正式 `Question.section` 为准，并按题目主知识点反向补齐知识点的所属节；这样可以覆盖早期知识树中知识点记录未直接保存节名称的情况。
- `/questions/catalog`、`/knowledge-points` 和班级学情接口均使用同一套正式知识点编码；图表标签显示“节 · 知识点”，避免同名知识点混淆。
- 旧历史作答记录仍按已有的题目快照和内部映射参与历史证据处理，但不作为新的学情目录展示项。

## 3. 后端调整

- `KnowledgePointOut`、`ClassKnowledgePointAnalytics` 增加 `section` 返回字段。
- 知识点目录查询支持可选 `grade` 参数，并按年级过滤可用题目、必做题数量和节映射。
- `/analytics/class-overview` 支持 `grade` 参数，班级知识点平均正确率按“年级 + 章节”查询。
- 正式题目目录接口补齐知识点到题目主属节的映射；未修改数据库表结构，也未新增素养算法相关表。

## 4. 前端调整

- 学生画像和班级学情均增加“年级 → 章节”的级联选择器。
- 学生画像直接使用正式题目目录中的知识点顺序和节信息，再将学生历史作答统计映射到正式知识点编码。
- 班级知识点平均正确率柱状图按正式知识点展示，并在标签中带出所属节。
- 原有作业进度、历史作答和基础素养雷达图保留；本次没有新增推荐练习、关注知识点或其他未提出的页面模块。

## 5. 数据与算法边界

当前知识点正确率仍来自已有确认作答统计，素养能力仍为阶段三基础值。年级和章节点筛选只是查询与展示范围调整，不代表画像更新算法已经实现；后续服务器部署并接入画像算法时，可沿用本次正式知识点编码和接口字段。
