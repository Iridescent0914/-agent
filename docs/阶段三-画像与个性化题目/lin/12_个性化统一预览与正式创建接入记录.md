## 1. 本次范围

本次将个性化模块接入现有班级作业统一预览和正式创建流程，形成：

```text
统一必做题 → 学生历史回顾题 → 学生个性化三题
```

预览仍为只读。正式创建不会复用前一次预览结果，而是在创建请求处理时重新读取每名学生的最新有效整数素养分并重新选题。

## 2. 正式业务口径

- 必做题先统一生成；
- 历史回顾题按学生生成，并排除必做题和历史来源作业中的题目；
- 个性化题最后生成，并排除该学生当前试卷已经选择的必做题和历史回顾题；
- 个性化模块固定请求 3 题，按基础、`+1`、`+2` 星精确选题；
- 预览允许返回缺题和逐星级诊断；
- 只要任一学生的个性化题不足 3 道，正式创建就在写入 Assignment、PaperInstance 前返回 422，不生成残缺正式作业；
- 正式创建使用创建时的最新分数；创建后题目和审计不随画像变化自动修改；
- 旧的预览结果不作为正式创建输入，因此预览后发生批改、改判或跨日回归时，创建结果可以合理变化。

## 3. 预览与审计字段

每名学生的预览新增 `personalized`：

- `literacy_name`：主要能力；
- `literacy_score`：唯一业务整数分；
- `score_source=computed`；
- `rule_version=literacy-dynamic-v1`；
- `base_star`；
- `target_stars`；
- 请求数、选中数、缺口、状态；
- 每个目标题位星级的题库、可机判、排除后库存和缺题原因。

每道正式个性化题在 `selection_audit.personalized_audit` 保存：

- 题位序号；
- 主要能力；
- 当时使用的整数素养分；
- 分数来源与规则版本；
- 基础星级；
- 当前题位目标题星和完整三星序列；
- 正式生成时间。

不保存 `internal_score` 或另一套显示分数。

试卷级 `recommendation_audit.personalized` 保存同一份学生预览摘要；作业级 `generation_config.personalized_score_policy` 保存“computed、整数、创建时重算”的统一策略。

## 4. 个性化换题约束

草稿换题时：

- 只允许教师原先选择的个性化知识点范围；
- 必须保持原题位的精确星级；
- 必须是未归档、可机判且已审核题；
- 不能与当前试卷其他题重复；
- 换题后保留原始整数分、基础星级、题位、规则版本和生成时间审计。
