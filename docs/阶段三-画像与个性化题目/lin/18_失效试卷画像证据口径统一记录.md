# 失效试卷画像证据口径统一记录

> 记录日期：2026-11-05
> 关联模块：学生画像、动态素养分、知识点回顾标签、试卷生命周期

## 1. 业务口径

撤回或被新版替代的已发布试卷保留试卷、提交、作答、批改和修订记录，用于历史查看与审计，但其作答不再参与当前画像计算。

当前有效画像证据必须同时满足：

```text
试卷已发布
且试卷未失效
且作答已自动确认或教师确认
```

撤回版本重新发布后，原有已确认作答重新进入画像。素养分不是直接加减历史增量，而是使用当前全部有效证据重新回放，因此能够继续遵守作答顺序、动态学习率、每日限幅和未练回归规则。

## 2. 实现调整

- 掌握度将失效试卷作答标记为 `invalidated_paper`，保留历史记录但不进入正确率和掌握度重放；
- `invalidated_paper` 属于正常业务排除，不计入损坏证据数量，也不会阻断画像重建；
- 动态素养分证据加载跳过失效试卷作答；
- 知识点回顾状态继续只读取当前有效发布版本；
- 撤回、重新发布和发布替代版本后，在同一数据库事务中刷新学生掌握度、素养分和知识点回顾状态；
- 历史作答抽屉和批改详情会明确显示失效版本不计入画像。

## 3. 数据处理

本次调整不删除任何试卷、提交、作答或修订记录，不需要数据库结构迁移。当前演示数据库检查时不存在“失效试卷且已有作答”的记录，因此不需要清理 Demo 数据。

其他环境若已经存在此类记录，应在部署后执行一次全量画像重建，使旧物化结果立即切换到统一口径。

## 4. 验证范围

- 已批改试卷撤回后，历史作答保留但掌握度和素养分回到排除该试卷后的结果；
- 撤回不会增加画像的无效证据数量；
- 撤回版本重新发布后，原作答重新进入画像；
- 已提交版本被新版替代后，旧版本作答退出当前画像；
- 批改详情和历史证据接口与画像计算使用相同的 `used_in_profile` 口径。
