# 画像与班级学情动态素养分接入记录

> 记录日期：2026-10-31  
> 对应拆解：`03_动态素养评分与个性化出题实施拆解.md` 第四部分  
> 关联记录：`01_基础画像展示调整记录.md`、`02_画像年级章节筛选与新知识点映射调整记录.md`

## 1. 本次范围

在动态评分规则、证据回放、持久化和写入事务闭环均通过测试后，将学生画像与班级学情的素养雷达图从固定基础值切换到动态计算结果。

接口现在返回：

```text
score_source = computed
rule_version = literacy-dynamic-v1
```

前端已有雷达图根据 `score_source` 判断提示，因此不需要修改组件：收到 computed 后自动停止显示“当前显示基础值，动态评分算法尚未接入”，改为“根据已确认作答计算”。

## 2. 学生画像口径

- 优先读取 `student_literacy_scores` 的 8 条同版本物化记录；
- 根据 `score_as_of_date` 只读补算截至查询日的未练回归；
- 服务器刚迁移、物化行缺失、版本不一致或物化日期晚于查询日期时，从当前有效证据只读回放；
- GET 请求不写数据库；
- 无证据学生返回 8 个 60 分，但数据来源仍为 `computed`，表示算法初始化结果而非临时占位。

## 3. 班级学情口径

- 先按学生分别取得同一套 computed 素养分；
- 班级每个素养取所有在读学生的算术平均值；
- 平均值保留 4 位小数；
- 素养雷达图是学生跨章节能力结果，不随知识点正确率图的年级、章节筛选改变；
- 知识点正确率、掌握度和作业进度继续使用原有口径。

## 4. 当前 Demo 可见结果

学生画像已经能显示真实差异。例如固定在 2026-10-31 的本地数据中：

```text

DEMO-S002：抽象 57.2422，运算 55.2445，几何直观 50.8594，推理 55.2445
```

班级学情接口同步返回 8 个 computed 平均分。

本次兑现 `01` 中预留的 `baseline → computed` 切换，保留原雷达图、知识点正确率和历史作答页面结构。

## 9. 2026-11-01 后续口径修正

本记录中的四位小数示例是数据库内部原始分，不再是画像接口的展示合同。`08_动态素养分取整每日维护与题目标签准入记录.md` 已统一为：

- 数据库内部继续保留四位小数；
- 学生画像和班级学情接口返回 `ROUND_HALF_UP` 整数；
- 个性化基础星级按同一个四舍五入整数分档；
- 后端跨日维护将未练回归结果写回数据库。
