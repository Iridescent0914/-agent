## 2. 数据口径

知识点正确率继续读取现有 `Attempt` 证据：

```text
正确率 = 已确认正确的作答数 / 已确认作答总数
```

`needs_review` 不进入统计；没有确认作答的知识点显示为空，不解释为 0。

素养能力暂时使用固定基础值 60，接口返回：

```text
score_source = baseline
rule_version = literacy-baseline-v1
```

当前固定维度为：抽象能力、运算能力、几何直观、推理能力、模型观念、数据意识、应用意识、创新意识。后续如甲方确认名称不同，只需调整静态能力目录，不需要数据库迁移。

## 3. 实现方式

- `ProfileOut` 增加 `literacies`，由静态基础目录生成；
- `ClassOverviewOut` 增加 `literacies`，暂时返回同一基础值目录；
- `KnowledgePointOut` 增加 `chapter_name`，用于学生画像章节选择；
- 前端新增知识点正确率柱状图和素养能力雷达图；
- 保留原有 Attempt、试卷快照、历史作答和作业进度接口；
- 保留旧画像字段及推荐接口的后端兼容能力，但不再在当前页面展示。
