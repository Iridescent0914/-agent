# 九项正式素养目录统一：第一步

日期：2026-11-10。

后续更新：本记录保留第一步完成时的范围与状态。2026-11-11已继续完成评分运行时、组卷筛选、雷达图与历史保护，当前状态以[记录23](23_九维素养评分与组卷画像统一记录.md)为准。

## 范围与口径

HTML 图谱的九项素养作为正式目录，顺序为：抽象能力、运算能力、几何直观、空间观念、推理能力、数据观念、模型观念、应用意识、创新意识。

“数据意识”是 HTML 中注明的“数据观念”的小学对应项，不作为初中正式标签的同义词。不能直接把旧分数或历史证据改名为“数据观念”。

本次是分步调整的第一步：统一正式目录来源和导出链路。评分运行时、组卷页面和历史数据处理尚未完成切换，不将此记录理解为九维全链路已完成。

## 实现

- `scripts/export_knowledge_graph_catalog.py` 的 `formal_question_labels.core_literacies` 改为直接使用 HTML 的 `COMPETENCIES`，不再单独硬编码八项。导出固定使用 LF，避免 Windows 生成整文件换行差异。
- 重新导出 `data/knowledge_graph_catalog.json`。目录仍为41章、345个 KP，其中只有前两章21个 KP 有正式编码；未扩大可入库章节范围。
- `knowledge_catalog.formal_literacy_dimensions()` 提供后端正式目录读取入口，并检查名称非空、无重复、名称及顺序与 HTML 衍生目录一致。KP 的完整素养集合校验复用该入口。
- 增加正式目录回归，覆盖九项及顺序、全图谱 KP 标签、空间观念与数据观念准入、拒绝数据意识，以及旧八项、缺项、重复、乱序和空名目录的拒绝。
- 原 KP 目录测试改为核对正式目录，不再把阶段三的八维评分常量当成全图谱正式标签依据。

`literacy_catalog.LITERACY_DIMENSIONS` 本次暂时保留旧评分版本的八项。后续须连同历史证据、物化记录和规则版本处理后再切换，不能现在只替换数组：运行中的后端会在热更新后的启动维护中自动重建分数，旧维度记录可能被删除。
