# 九维素养评分、组卷与画像统一记录

日期：2026-11-11。承接[记录22](22_九项正式素养目录统一记录.md)的正式目录调整，完成剩余运行链路与验证。

## 1. 正式口径与目录来源

正式维度及顺序为：抽象能力、运算能力、几何直观、空间观念、推理能力、数据观念、模型观念、应用意识、创新意识。

HTML 的 `COMPETENCIES` 是维护来源；导出器直接将其写入 `data/knowledge_graph_catalog.json` 的正式素养枚举。后端 `formal_literacy_dimensions()` 校验目录与 HTML 衍生字段的名称、顺序和唯一性，`literacy_catalog.LITERACY_DIMENSIONS` 直接读取该入口，不再维护独立八项常量。

“数据意识”是 HTML 解释中的小学对应项，不是初中“数据观念”的别名。系统不执行同义词替换，也不将几何直观分数复制成空间观念分数。

仍只有前两章21个 KP 可入库；完整目录的41章、345个 KP 和正式编码开放范围不变。本次没有扩章、造题或接入视觉模型。

## 2. 组卷筛选、选题和题库准入

- 新增只读 `GET /api/v1/questions/literacy-dimensions`，返回正式九项及顺序。
- 必做题筛选移除页面硬编码，读取该接口，补齐原来遗漏的“创新意识”。
- 个性化主要能力继续由所选 KP 的能力集合确定，并按正式目录过滤和排序；不能因为有九项就给所有 KP 强加九项。
- 必做题筛选与主要能力请求增加正式名称校验，“数据意识”及未知字符串返回422。正式名称还须满足所选 KP 的能力范围。
- 个性化预览、生成、草稿换题和发布沿用同一目录。三个精确星级题位、卷内去重、近期排除及缺题阻断规则不变。
- KP 派生题目完整素养、种子导入、答案审核晋级及发布校验均使用正式目录；旧撤回试卷重新发布也检查标签。现有发布快照与历史选题审计不被改写。

## 3. 九维评分与班级平均

评分版本升级为 `literacy-dynamic-v2`，旧占位基础目录版本同步为 `literacy-baseline-v2`。每名学生物化九条记录，新维度在没有证据时从60分、0次作答开始；班级平均按相同九项聚合。

评分数学参数不变：难度映射、学习率、选择题猜测修正、日净变化限幅、未练回归和整数分档沿用原规则。一题只在其关联素养间平分权重 `1 / 关联素养数`，不会因为目录变为九项而将所有题统一除以9。

人工提交、图片确认、改判、撤销确认、重新评分、统一画像重建和每日维护均通过既有评分服务接入九维。旧版本或维度不完整的物化结果不会被当作当前结果使用。知识点 EMA、正确率和“是/否/弱”规则未调整。

## 4. 历史证据保护与转换命令

历史评分仍依据题项发布快照，不按当前题库标签解释旧作答。有效快照中出现“数据意识”时，诊断包含 `legacy_core_literacy_requires_review`、作答ID和修订号，并阻止重算；不能静默跳过或改名。

旧维度物化记录若有非零作答次数、非60分或非空最后练习时间，也会阻止自动转换并保留原记录。只有旧行完全是无证据初始化值、且学生的有效作答证据均通过检查时，才允许删除旧初始化行，同时分别建立空间观念与数据观念的初始化结果。

新增 `scripts.transition_literacy_dimensions`：

- 默认预演，计算前后结果后回滚；`--apply` 才提交。
- 提交前核对所有在读学生，任何学生存在未解决证据或旧维度学习记录时，整批不写入。
- 提交时锁定学生；单学生处理中出现异常，整个提交事务回滚。
- 报告保存每名学生前后分数、版本、答题次数、最后练习时间及阻断原因；不自动修复或猜测历史分类。
- 前后检查8张业务保护表的数量与内容 SHA-256，出现变化则拒绝提交。
- `--as-of` 是基于当前最终修订的计算截止时间，不是恢复当时修订状态。

```powershell
docker compose exec -T backend python -m scripts.transition_literacy_dimensions --output /app/data/uploads/literacy_transition_preview.json
docker compose exec -T backend python -m scripts.transition_literacy_dimensions --apply --output /app/data/uploads/literacy_transition_applied.json
```

旧环境切换前应先备份并预演；后端启动的自动维护也会尝试重建，因此需要预先审计时应暂停服务、使用一次性容器或隔离库。不要通过编辑历史快照、直接改名旧分数或跳过报错强行完成转换。评分表按素养名称存行，本次无须增加字段或新建评分表；已有环境仍需完成此前 `0026`～`0028` 的目录迁移。

## 5. 雷达图与页面

学生与班级雷达图按接口九项生成轴，桌面和390px页面均核对轴标签和布局。班级平均的名称、数量或评分版本不匹配时隐藏班级曲线并提示重新加载，不再用0填补缺失维度。

页面说明没有证据的维度从60分初始化，避免将初始化分数误读为已经测得的能力。原有班级平均加载失败与重试流程继续保留。
