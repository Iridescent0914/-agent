# 动态素养评分纯算法规则实现记录

> 记录日期：2026-10-31  
> 对应拆解：`03_动态素养评分与个性化出题实施拆解.md` 第一部分  
> 范围：纯算法内核和单元测试，不接数据库、不切换画像展示。

## 1. 本次实现

依据修改版机制说明，完成以下规则固化：

- 保留 `1～5 星 → 30、45、60、75、90` 的难度值映射；
- 保留 Logistic 预期正确率、动态学习率、`0～100` 分限制和单日 `±8` 限幅；
- 选择题支持按选项数计算猜测概率，缺少选项数量时回退到四选一的 `0.25`；
- 多素养题改为去重后严格均分权重；
- 基础星级改为修改版规定的固定分数区间；
- 新增个性化三星序列：基础星级、`+1`、`+2`，统一执行五星封顶；
- 新增每天向 60 分回归 1% 的纯函数；
- 新增显示层四舍五入函数，计算过程继续保留小数；
- 删除不属于修改版需求的 `70/20/10` 题量混合函数；
- 删除按目标正确率反推星级的旧规则，避免与固定分数区间并存。

## 2. 关键口径

基础星级边界为：

```text
[0, 60)   -> 1 星
[60, 70)  -> 2 星
[70, 80)  -> 3 星
[80, 90)  -> 4 星
[90, 100] -> 5 星
```

个性化题难度序列为：

```text
1 -> 1、2、3
2 -> 2、3、4
3 -> 3、4、5
4 -> 4、5、5
5 -> 5、5、5
```
