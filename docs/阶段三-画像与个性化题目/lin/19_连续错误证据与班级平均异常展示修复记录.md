# 连续错误证据与班级平均异常展示修复记录

> 记录日期：2026-11-05
> 关联记录：`17_知识点回顾标签表格化记录.md`

## 1. 连续错误证据链

知识点状态不再仅凭题目的 `source_module` 生成。“否”必须满足：

1. 历史回顾题的 `selection_audit.evidence` 能定位来源作答；
2. 来源和回顾作答属于同一学生、同一知识点，来源时间早于回顾；
3. 来源作答所属试卷当前有效，且来源作答当前仍为已确认错误；
4. 来源错误和历史回顾之间没有该知识点的已确认正确作答；
5. 历史回顾本次也为已确认错误。

历史回顾答对生成“是”时同样要求来源错误证据有效。来源作答后来被改判正确、来源版本失效、知识点不一致或中间已经答对，都会使这次历史回顾不再生成“否”。

周总结的“弱”会继续核验其引用的历史回顾错误，并要求该历史回顾本身具有完整的“日常错误 → 历史回顾错误”证据链。

## 2. 班级平均异常展示

学生画像中的班级平均请求增加独立的加载、成功和失败状态：

- 请求开始时清空旧班级数据，避免切换章节后短暂展示旧数据；
- 加载时显示“正在加载班级平均数据”；
- 只有请求成功后才展示班级平均系列和显示开关；
- 请求失败时保留学生数据，隐藏知识点和素养图中的班级系列；
- 失败时显示错误说明和“重新加载”按钮。

素养雷达图不再用学生分数冒充班级平均，知识点图也不再把缺失的班级数据渲染为 0%。
