# 知识点回顾标签表格化记录

> 记录日期：2026-11-04  
> 关联记录：`16_学生画像与历史作答章节筛选统一记录.md`

## 1. 调整范围

学生画像中的“知识点回顾标签”由只显示已有状态的标签集合改为完整章节表格，并继续复用学生详情公共的年级、章节筛选。

表格固定三列：

1. 本章知识点；
2. 是否为“否”；
3. 是否为“弱”。

本章全部正式知识点都会显示。尚未进入回顾状态计算的知识点显示“未标记”，不会误解释为“否”。

## 2. 状态展示

- `yes`：是否为“否”= 否，是否为“弱”= 否；
- `no`：是否为“否”= 是，是否为“弱”= 否；
- `weak`：是否为“否”= 是，是否为“弱”= 是；
- 无状态：两列均显示“未标记”。

“弱”是“否”之后在周总结中再次出错的递进状态，因此会同时保留“是否为否”的肯定标记。

表格下方增加说明：

```text
说明：“否”为日常作业中连续错两次，“弱”为周总结中也出错。
```

## 3. 规则复核

后端 `knowledge_status.py` 通过历史回顾题结果生成 `yes / no`，通过周总结同知识点题组结果生成 `yes / weak`。历史回顾题的来源是此前日常作业中的错误题，因此历史回顾再次出错对应业务上的连续两次错误。

2026-11-05 补充：状态重放不再只信任 `source_module=history`，而是读取 `selection_audit.evidence`，核验来源作答当前仍为错、试卷仍有效、知识点一致、时间顺序正确且中间没有已确认正确作答；周总结状态也会验证其引用的历史回顾错误仍具有完整证据链。详见 `19_连续错误证据与班级平均异常展示修复记录.md`。
