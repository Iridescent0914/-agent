# 班级学情素养雷达图单序列展示调整记录

> 记录日期：2026-11-01  
> 关联记录：`01_基础画像展示调整记录.md`、`07_画像与班级学情动态素养分接入记录.md`、`08_动态素养分取整每日维护与题目标签准入记录.md`

## 1. 调整原因

班级学情页原先将同一份班级素养平均分同时作为“学生”和“班级平均”传入雷达图，导致两条完全重合的曲线，并出现“显示班级平均 / 隐藏班级平均”的无意义切换。

## 2. 调整内容

- 班级学情页只向雷达图传入一份班级素养平均分；
- 单一序列的图例名称改为“班级平均”；
- 班级学情页不再显示“显示班级平均 / 隐藏班级平均”开关；
- 雷达图继续展示班级接口返回的 8 项动态素养平均分；
- 学生画像页的“学生 + 班级平均”对比和切换能力保持不变。

## 3. 实现方式

`LiteracyRadarChart` 新增可选的 `seriesName` 参数，默认仍为“学生”。班级学情页传入 `seriesName="班级平均"`，且不再传入 `classAverage`，因此只绘制一条班级平均曲线。

本次只调整展示层，不改变动态素养分的计算、取整、持久化和班级平均聚合口径。
