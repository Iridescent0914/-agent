# S3：自动整批去重与参考答案分界

> 本文记录 `question-import-combined-v7` 阶段的处理。后续 `v8` 已允许答案章节的完整题先进入候选，再由整批去重判断；见 [15 答案章节完整题提取与去重资产边界](15_答案章节完整题提取与去重资产边界.md)。当前整批去重仍是一次模型调用，输入超过 150,000 字符会失败，跨全批召回后分组判重尚待实现。

## 本次问题

- S2 完成后，整批模型去重仍需手动点击，用户会先看到大量答案区重述题。
- 题答同文件中，明确的“参考答案”标题后仍可能被当成题目区读取。
- 答案校对按钮受旧版关联状态限制而消失；上传场景默认“只有题目”也容易导致不提取答案。

## 已实现

1. 新启动的 S2 批次在全部页段完成后，由后台自动调用整批模型去重；去重后自动执行原文答案关联。整批调用发送所有候选题的完整题干与选项，单次输出上限提高到 8192 Token。自动调用使用启动 S2 时确认的预算剩余额度。额度不足时显示待补预算，仍可手动点击“增加预算并整理整批”。已完成的历史批次不会未经用户再次操作而自动产生模型费用。
2. 题答同文件的新批次使用 `question-import-combined-v7`。可搜索文字中的“参考答案”“参考答案与解析”“参考答案及解析”等明确章节标题用于跨页段传递答案区边界；答案区页面不建立新题候选，只提取原文答案。标题所在混排页由模型按标题前后内容分别提取。扫描件没有可搜索文字时，仍由视觉模型根据页面内容判断。
3. “校对题答”按钮在已完成 S2 的题答同文件批次中始终显示，可重新计算已有原文答案的关联。上传场景默认“题目与答案同文件”；用户仍可选“只有题目”。

## 已处理的现有批次

批次 `fa0a8c17-bcb1-4ea3-895a-9aa5516d9523`（《2026年中考数学真题知识点分类汇编之有理数（一）.docx》）是旧版 v5 批次，原有 42 道候选和 43 条原文答案，但整批判重与答案关联未执行。本次在其原设预算剩余额度内执行：整批模型移除 20 道重复候选，剩余 22 道；22 道均关联了原文答案。43 条原文答案中，18 条是重复记录，1 条是跨页重复，2 条仍未确定归属。原文件转出的 18 页 PDF 可搜索文字显示第 4 页进入“参考答案”混排，第 5–13 页为答案区。

## 验证

- 后端定向测试：39 通过；全量测试：312 通过。
- 前端 `npm run build` 通过。
- 本地批次数据库核对：42 → 22 道候选，22 道有答案关联。

注意：v7 只用于新启动的题答同文件批次；已经按 v5/v6 开始的批次继续沿用原提示词，避免中途切换付费调用契约。整批模型判重仍受单次文本上下文容量和模型判断准确度限制；超出容量或预算时会在批次中标明未完成。

## 题答关联延迟与题号摘录修复

- S2 逐页段保存题目与原文答案后，后台才会整批去重并关联题答。因此 S2 刚结束时，候选题内可能暂时没有答案。候选详情现在直接显示原文答案提取数和已关联题目数；弹窗打开期间每 10 秒刷新候选题，关联完成后无需关闭重开。
- 模型有时把答案对应的题干摘录写成“第21题”。这只有题号，不是可用于比对的题干内容。此前它被当成题干冲突，挡住了正确答案。现在只用有实际题干内容的摘录做冲突检查；原有真实题干冲突仍不自动关联。
- v7 批次 `74935d6f-431c-448d-811a-6900cd2fcdcd`（《题答同文件测试（一）.docx》）重新关联后为 22 道题、22 道有答案；另有 1 条无题号的原文答案片段无法确定归属。重新关联没有再次调用付费模型。
- 后端 S3 测试 16 通过；前端 `npm run build` 通过。
