# 取消批次永久删除

日期：2026-11-18。

## 行为

- 点击批次的“取消”先弹出确认框，提示取消后当前无法恢复、需要重新上传文件才能继续导入，并说明暂存数据不会立即删除；只有确认后才发送取消请求。
- 批次列表只为 `cancelled` 状态显示“永久删除”按钮；点击后再次确认，明确提示数据无法恢复。
- `DELETE /question-imports/{batch_id}` 只接受当前使用范围内的已取消批次。若仍有正式题库题目引用该批次或其中的候选题，拒绝删除。
- 删除批次数据库行及级联的暂存候选题行。批次检查点中的模型调用、来源答案、标签建议和费用记录随批次行删除；候选题 payload 中的题干、答案、标签及图片关联随候选题行删除。
- 删除该批次专属目录中的所有文件，包括原 PDF/DOCX、模型响应缓存、识别出的题图和教师上传的题图。目录路径由批次 UUID 生成，删除前校验其位于配置的导入根目录内。已经过期清理的批次也可删除数据库记录。
- 删除失败时返回错误；不会把其他状态的批次或其他批次目录纳入清理。

## 验证

- 定向测试覆盖已取消批次的数据库行、候选题行、源文件及附属文件清理，以及未取消批次的拒绝：2 项通过。
