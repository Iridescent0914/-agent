# 分文件答案 PDF 的页段与重试费用优化

## 范围

仅改变“题答分文件”的答案文件识别。所有答案页，包括文字清晰的页，均提交给百炼模型转录，不再本地生成来源答案。题目文件和题答同文件保持原流程。

## 页段与重试

1. 按配置页数分组，默认每段 4 页主体，通常附带下一页作上下文。只有本地文字明确显示前一页答案结束、下一页开始独立题目或章节时，才省略上下文页；边界不清时继续附带。末尾短页已在上一页段上下文中时，并入上一页段主体，避免重复调用。
2. 模型返回 complete=false 和 incomplete_from_page 时，只有此前每页都有答案或未解决片段记录，才复用已完成前缀并重试后缀。无法确认前缀覆盖、标记缺失、响应截断或跨页答案无法安全切开时，沿用拆分页段重试。
3. 本地页段规划发生异常时，退回原固定页段方案。

## 费用与审核

取消本地答案提取后，不再以本地识别页数节省 PDF 解析费；明确边界时省略上下文页、失败时缩小重试范围仍可能减少重复解析。若模型返回 token 用量但漏报 PDF 解析页数，按实际提交的页数估算费用；实际应付金额以百炼账单为准，系统预算仍是估算停机阈值。模型转录结果仍需教师对照原页审核。
