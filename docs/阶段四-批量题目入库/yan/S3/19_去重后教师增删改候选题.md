# S3：去重后教师增删改候选题

候选题工作台允许教师修改题干、选项、答案与题图，并新增或删除题目。题答同文件、只有题目两种场景须先完成整批去重；题答分文件须先完成整批去重和答案文件识别。标签建议排队或生成期间暂停增删改，任务结束后可继续操作；因此既能在打标签前处理，也能在打标签后处理。题图自动提取与自动裁剪仍属于原识别流程，不受教师操作条件影响。

- 编辑答案时新增 `teacher_entered` 版本并保留资料答案；编辑题目或答案会撤销已有题目审核决定，编辑题目还会标记标签建议过时并提示重核答案。保存使用 `expected_revision` 防止覆盖并发修改。
- 新增题目记录教师新增时间、可选原题号与来源页，答案可选。新题的入库标签为空，需教师核对重复情况并补全标签；题图仍通过现有图片关联或上传接口处理。批次最多保留 200 道有效候选题。
- 删除使用候选题内的 `teacher_deleted_at` 软删除。原记录保留供追溯；有效候选题列表、答案关联、标签任务、题图列表和原页复核不再使用该题。删除也校验版本号。
- 新增或删除不会自动重算整批答案关联，以免改写其他题已有的教师答案和资料答案版本。已有关联保持原样；若批次已有答案关联统计，会标记其基于增删前的快照，前端提示人工核对。新增题可以填写教师答案，或之后编辑答案。

验证：前端生产构建通过；后端容器中的候选题、标签、题图、题答关联和原页复核定向测试共 59 项通过。新增测试覆盖两种解锁条件、答案版本、软删除、列表过滤和版本冲突。
