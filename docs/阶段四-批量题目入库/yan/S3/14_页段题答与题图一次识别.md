# 页段题答与题图一次识别

日期：2026-11-16。新建批次从 S2 开始启用；已完成 S2 的旧批次保持原识别结果，不在后台自动产生第二次付费调用。

## 流程

1. S2 工作器准备题目 PDF 后，用 PyMuPDF 扫描整份文件中独立存放的位图，记录原页码、归一化位置和私有 PNG。DOCX 仍先使用已校验的转换 PDF。
2. 每个 S2 页段在**同一次模型调用**中发送 PDF 页段、逐页渲染预览、该页段已有位图的 ID/页码/位置。模型仍提取题目；题答同文件时仍提取原文答案。每道题另外返回 `figure_status` 和 `figures`：位图本身是独立、完整题图时引用其 ID，缺少现成图的返回 0–999 归一化页坐标。整页扫描图或多题拼图应输出具体题图坐标；跨页图按页分别列出。
3. 服务端验证图片 ID、来源文件、页码范围、坐标数值和区域大小，并拒绝将整页扫描位图直接关联为单题题图。有效坐标由服务端渲染原 PDF 生成 `model_crop`；有效图片引用和裁剪结果直接写入该候选题 `content.asset_ids`。无效或不确定的结果留下候选题警告，不能伪造关联。
4. 导入页不展示 PDF 原页，也不提供人工框选裁剪。自动关联的图片直接显示在对应候选题的题干和选项后；未关联的自动图片集中显示在候选题上方，并提示“无法匹配到题目，请人工复核”。没有关联图但有题图线索的题目显示线索和“题图尚未裁剪；请对照原页复核”。每道候选题可上传 JPG、PNG 或 WebP 图片；已关联图片可删除。上传图暂存于批次并只关联上传时的候选题，删除后移除暂存文件。教师最终确认、正式图片晋级仍属于后续步骤。

## 边界与验证

- 坐标可用性尚未通过真实含图资料评测；不能预先断言可靠或不可靠。当前只完成请求契约与服务端安全校验，需用人工标注的 PDF 测量题图召回率、坐标框偏差、题目匹配准确率，再决定是否进一步放开自动入库。
- 模型坐标只用于服务端裁剪，不让模型直接生成或写入图片文件。模型无法确定图或题目归属时返回 `uncertain`，保留核对提示。旧批次如果未运行新版 S2，不会自动得到模型题图匹配。
- 已完成 S2 的旧批次无法追溯成“一次调用”；要使用这一流程需创建新批次。旧批次原有图片暂存和人工校正入口保留。
- 自动化测试覆盖：单次请求同时包含 PDF、页图、位图清单，并解析题目、答案及题图；S2 工作器自动裁剪并写入题目；已有位图复用、跨页/非法引用和整页扫描图误关联拒绝；逐题上传、删除和版本冲突；现有 S2 断点、题答和 S3 去重测试保持通过。尚未执行真实付费模型调用。
