## 问题复现

同一份 `2026年中考数学真题知识点分类汇编之有理数（二）.docx` 在旧版题答同文件流程中得到 16 道候选、16 道带答案的题。v5 S2 得到 26 道候选和 18 条资料答案，但当时尚未执行 S3 对账，界面显示 0 道带答案的题。多出的 10 道候选位于后面页段，是答案区把前面的题目重述了一遍。它们与原题相隔数页，不会命中只检查相邻页段的 `overlap_suspects`。

## 当时处理顺序

1. S2 分页段调用模型，分别提取候选题和原文答案；保留原页码与来源记录。
2. 操作员点击“模型整理整批题答”后，S3 **整批模型判重**才会启动；S2 完成时不会自动调用。一次发送该批所有候选题的题干摘录（每题最多 700 字）、选项、题号、来源页码，以及已提取答案的摘录（各最多 180 字）。模型返回保留候选 ID、删除候选 ID、类型和判断依据。后半部分答案区重述前面题目时，也可以跨页段判断。调用要求操作口令和预算阈值；文字总量超过单次上限时会拒绝调用，不会自动分组。
3. 服务端校验模型返回的候选 ID 后，删除重复候选；被删除候选的完整 payload、保留 ID 和模型依据保存在 `checkpoint.s3.model_removed_duplicates`。人工编辑或答案冲突的候选不覆盖。后续新增候选使用最大序号加一，避免删除后序号冲突。
4. 对剩余候选执行 S3 资料答案关联。短题干摘录只要有足够辨识度，也参与匹配。未能关联但具有可召回候选及有效原页的答案，自动把相关原 PDF 页发给模型复核；模型确认归属后自动写入候选答案，仍标记为未由教师确认。
5. 页面显示整批判重数量、候选题旁的答案和原始提取答案；仍未关联的答案也显示在相关题号旁，避免“答案消失”的错觉。

整批首轮判重使用提取后的文字与答案摘录，未重新发送整份 PDF；只有剩余答案归属问题使用相关原 PDF 页。页面另有“仅关联资料答案”入口，可以跳过整批判重，因此上述顺序是点击“模型整理整批题答”后的流程，并非所有 S3 操作的强制顺序。模型未列出的重复题仍可能漏掉，文字截断或模型误判也可能影响结果。S4/S5 的正式入库审核尚未完成。

## 实际批次处理结果

批次 `bc759c6d-bb10-457c-976e-962b3e894b36`：整批模型比较 26 道候选，判为重复并移除 10 道，剩余 16 道。18 条原文答案中，16 条最终关联到 16 道题；2 条识别为跨页重复答案；待认领答案 0 条。第 11 题的答案先因题干摘录格式差异暂缓关联，随后用原 PDF 第 1、6、7 页复核，模型返回 `match_candidate` 并自动关联。整批判重服务未返回可用费用估算；这次原页复核返回的估算为 ¥0.071823。
