# 移除原页模型复核，保留教师问题清单

日期：2026-11-18。

## 调整后的行为

- 导入页保留三类问题：题答同文件的待认领答案、S2 未确定片段、跨页段疑似重复题。每条显示来源页、原始内容或原因，以及相关候选题，供教师根据原文件人工核对。
- 删除“发送原页复核”和“按页段一次复核”按钮；删除对应 POST 接口、模型请求与批次复核预算流程。保留问题清单的只读 GET 接口；接口和页面均不返回、展示历史模型建议。
- 问题清单中的相关来源页不再受旧模型请求“最多 4 页”的限制；缺少结束页时按起始页显示。清单仍只展示最多 8 条相关候选题，超过时显示实际候选总数。
- 页面使用“待教师核对的问题 → 问题类型 → 具体问题”的折叠层级。三类问题各有独立的子折叠框、数量和视觉缩进。
- 整批模型去重是独立任务，继续只发送候选题文字和题答同文件的来源答案摘录；其删除重复候选的通用逻辑已移到整批去重服务。整批去重后，资料答案仍由程序按规则保守关联。分文件答案识别、标签建议不受本次调整影响。
- 没有数据库迁移，也不清除旧批次的调用记录与费用审计；历史复核建议只留在旧批次检查点中。

## 验证

- 后端问题清单与整批去重定向测试：7 项通过，覆盖三类问题只读展示、答案问题稳定编号、历史建议不再返回、来源页不受旧模型请求页数限制、付费原页复核路由不存在、整批去重仍可执行，以及去重时答案和图片资产不被错误转移。
- 前端 TypeScript 检查和生产构建通过。
