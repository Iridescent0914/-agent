# 裸 LaTeX 成对括号渲染修复

## 现象与定位

2026-11-16 21:26:52 创建的导入批次中，序号 80、81、82 的题目包含 `\left(-\frac{5}{4}\right)`、`\left[-\left(-\frac{1}{4}\right)\right]` 等公式，预览显示异常。S2 已将题干和小题内容写入候选题；这些题的 `math_fragments` 为空，但题目文本保留了原始 LaTeX 命令。问题出在前端 `RichQuestionText` 对裸 LaTeX 的拆分：原规则从内部 `\frac` 开始匹配，把前面的 `\left` 和后面的 `\right` 留作普通文本，导致公式被拆断。

## 修改

- 在裸 LaTeX 拆分时，先识别完整的 `\left...\right`，按嵌套层级寻找配对的右界符，并将整个片段交给公式组件渲染。
- 配对查找限制在当前行，避免未闭合的 `\left` 吞掉下一小题的内容。
- 保留原有 `\frac`、`\times` 等普通裸公式的识别方式。已有候选题只需重新打开页面即可使用新的展示解析，无需重新识别或改写题目数据。

## 验证

- 从修改后的源码提取解析函数，使用序号 80～82 对应的 5 个成对公式片段验证，均作为完整公式输出；嵌套括号和未闭合括号后的下一行分数也通过。
- `npm run build` 通过，包含 TypeScript 检查和 Vite 构建。

本次修复范围是题目展示解析，不改变 S2 提取结果、答案匹配或入库数据。
