# 题答混排页边界保护

> 历史开发记录：本文的 v3/v4 同文件提示词已从运行时代码移除；当前版本见 [提示词版本与历史兼容清理](../S2/14_提示词版本与历史兼容清理.md)。

> 本文记录 v3 方案。新批次已改用模型逐段判断的 v4 方案，见 [06 模型判断题答区域](./06_模型判断题答区域与非独立题.md)。

## 问题

S3 曾按整页章节类型清理误识别候选。如果一页上半部分仍是独立题目、下半部分才进入“参考答案与试题解析”，整页被标为答案页时，上半部分真题也可能被自动排除。S2 同样可能因此丢掉模型在该页提取的题目。

## 处理

- `pdf_page_roles` 检查页面全文的显式章节标题，识别“题目部分”“参考答案与试题解析”“考点卡片”等切换。标题前已有内容，或一页内出现多次章节切换时，整页标记为 `mixed`；同时记住最后一个标题，供后续无标题页面判断章节。
- S2 联合提取提示词升为 `question-import-combined-v3`，要求模型在混排页按页内标题前后的区域分别提取独立题目与资料答案。程序保留 `mixed` 页的题目候选，只自动忽略明确处于纯答案页或纯参考资料页的题目重述。
- S3 清理旧候选时也保留 `mixed` 页，不依据整页标签自动排除。已有教师编辑的候选仍沿用原有保护。
- 前端 S3 关联入口接受 v3 批次；旧 v1/v2 批次仍可按原有流程校对。

这个改动对新识别批次生效；已经识别并人工核对的批次不会自动重新调用模型或重建候选。混排页中答案区的题目重述有可能继续留在候选列表，须人工核对。若 PDF 文本层缺少或错读章节标题，当前规则也无法可靠确定页内边界，不能把程序判定视为最终教师确认。

## 验证

- 测试覆盖页内章节切换、后续页继承章节、S2 保留混排页真题及 S3 不删除混排页候选。
- 后端全量测试：`294 passed`；前端 `npm run build` 通过。
