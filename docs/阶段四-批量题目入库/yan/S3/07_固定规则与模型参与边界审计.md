## 已实现链路中需要改进的语义规则

| 优先级 | 现有判断 | 超出规则时的影响 | 建议 |
| --- | --- | --- | --- |
| 高 | S2 跨页候选使用题号、页距、数字集合、选项及文本相似度阈值判断重复，命中后自动合并并可能替换原候选。见 `question_import_s2.py` 的 `overlap_candidate_is_duplicate`、`prefer_incoming_overlap` 和 worker。 | 同页相似但并非同题的题目可能被误合并；公式或题号漏读也可能使真重复留下。worker 的合并记录不含被替换候选的完整 payload，原响应文件会按临时资料规则清理。 | 精确一致可程序去重；其余进入“疑似重复”并保存两个完整候选。让模型结合原页图像、题干及选项给出是否同题的建议和证据，教师确认前不删除。 |
| 高 | S3 用归一化题号在整批候选中找唯一匹配；仅在非唯一时尝试 `question_excerpt` 的长度至少 16 的包含匹配。见 `question_import_s3.py` 的 `_matching_excerpt`、`reconcile_source_answers`。 | 题号缺失、重排、多套题重复编号或题干改写多数会进入待认领；少数摘录唯一的情况能关联。题号虽唯一但答案来源与候选不符时仍可能误关联。 | 对题号冲突、缺失、摘录不一致的答案，让模型在候选题和原文页段中提出可能配对及原文依据；程序校验真实候选 ID、页码和冲突，无法唯一确定则待认领。即使题号唯一，也应检查已有摘录是否矛盾。教师最终确认。 |
| 高 | 新版联合提取 v4 已由模型判断题目、答案重述和讲解例子，但输出契约只给 `answer_restatement`、`reference_material` 两种非独立题类别，题目为 `independent_question` 或 `uncertain`。见 `question_import_s2.py` 的 `ClassifiedModelQuestion`、`ModelNonquestionFragment`。 | 目录、示范解法、活动说明、答题卡等其他内容没有恰当类别；模型可能漏报或硬塞进已有类别。非独立题只保存简短摘录；原件过期后，误判的真题难以从现有候选恢复。 | 保持模型参与，增设其他类型及不确定原因的兜底；保存足够完整的原文与页证据，提供教师复核及恢复为候选的路径，不能把模型分类当作不可逆删除指令。 |
| 中 | 上传场景只由用户选择 `questions_only`、`combined`、`separate`；S2 只读标为题目的文件，已实现的 S3 只处理 `combined`。见 `question_import.py` 和 `question_import_s2_worker.py`。 | 用户误选“只有题目”而文件含答案时，当前链路不会提取来源答案；分文件答案处理尚未实现。 | 模型在原有 S2 阅读中报告实际内容与所选场景是否冲突，给出页码证据并提示用户；不要擅自更改场景。分文件答案须按 S3 计划单独实现。 |
| 低 | 跨页无题号答案仅在相邻两页段首尾、文本归一化后完全一致等条件下归为重复。见 `question_import_s3.py` 的 `_classify_overlap_duplicates`。 | 同一答案的公式写法或措辞变化时留在待认领；当前不会强行错配。 | 保留精确规则的自动分类；对其余疑似重复可由模型提出建议，但不得自动丢掉原始答案。 |
| 低 | `resolved_overlap_option` 仅识别 `A.` 等拉丁字母选项，并要求与前页已挂选项完全一致。见 `question_import_s2.py`。 | 其他编号写法会留在未确定片段；目前不会丢失原文。 | 可先扩充结构解析；对仍无法归属的碎片，模型结合跨页上下文建议归属并保留待核对状态。 |

旧版题答联合提取 v1～v3 仍保留 `pdf_page_roles` 标题名单和整页类型判断，以便已付费未完成批次继续使用原输出契约；**新建 v4 批次不使用该规则**。已完成批次不会自动重新识别，历史结果仍须按原批次审阅。

## 应由程序或正式目录控制的名单

| 规则 | 原因及处理边界 |
| --- | --- |
| PDF/DOCX 文件类型、文件头、宏/加密/压缩检查、页数和费用上限 | 属于安全、兼容性和资源限制。模型不能替代格式解析、病毒/宏限制或预算控制；若要支持新格式，应先实现可靠转换与校验。 |
| DOCX OMML 公式和图片转换检查 | 转换后若内容已经消失，模型无法从缺失的 PDF 恢复原公式。应修转换器并做原件对照；模型只能协助发现可疑缺字。 |
| 正式 KP code、九项素养和题型/难度枚举 | 这是题库契约与业务范围，不应让模型自行扩大白名单。后续 S3 可让模型在正式目录内建议 KP、题型和难度，返回 `needs_confirmation`/`out_of_scope`；新 KP 需由教师与目录治理流程增加。 |
| 批次状态、教师决定、答案确认、版本冲突与来源 ID | 属于权限和数据一致性约束，必须由服务端校验。模型只能提供建议，不能替教师确认或改变已审核状态。 |
| 公式显示组件可识别的 LaTeX 形式 | 这是渲染/解析能力边界，优先使用可靠数学语法解析和原文核对；不应靠模型猜测展示或改写原始公式。 |

## 尚未实现，后续按 S3～S6 计划处理

- S3：分文件答案、题图资产与归属、模型生成答案、题答预审、KP 建议仍未完整实现。题答错位、图片归属、KP 建议需要模型提供**有证据的建议**，并保留待认领和教师确认路径。
- S4：正式题库相似题查重尚未实现。先用精确哈希和索引召回候选，再对疑似变式使用模型辅助比较；不能仅凭标签不同跳过，也不能让模型直接覆盖既有题。
- S5/S6：审核工作台和正式提交仍未完成。模型建议不能绕过教师确认、目录白名单、最终查重和事务性入库校验。

建议先处理**跨页候选自动合并**、**v4 非独立题的可恢复性**和**题答关联的题号依赖**；它们分别可能导致漏题、误判后无法恢复和错配，影响比保守保留未确定片段更大。设计变更应先用标注过的跨页题、重复编号、错位答案和无标题资料评价误删、漏检、错配及费用，再决定自动处理阈值。
