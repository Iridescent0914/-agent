# 资料答案自动选定与旧批次修复

日期：2026-11-26。

## 问题

2026/11/24 15:43:38 创建的同文件批次中，22 道候选题各关联了一条资料答案，`answer_match_status` 为 `matched`，但 `selected_answer_id` 为空。S5 审核弹窗只显示当前选定答案，于是误显示“未选择答案”。原 S3 测试也明确要求关联后不自动选定，导致教师必须再操作一次；界面此前没有提供直接选用已关联答案的入口。

## 调整

- S3 将明确关联到某题的资料答案自动设为该题当前答案。此处的“当前答案”只是默认使用的答案版本，**不代表教师确认答案内容正确**；S5 直接入池仍需提交独立的结构化答案审核。
- 保留模型辅助配对对自动关联答案的检查能力；教师已编辑的答案、已有人工决定或有歧义的多版本答案不会被自动覆盖。
- S5 单题弹窗和候选列表现在可展示并手动选用未选定的已关联答案；批量审核预览也区分“当前答案”和“已关联但未选定的答案”。
- 仅对批次 `133d470b-c266-4c61-bcd9-081330789813` 进行一次安全补选：22 道题均为待审、每题只有一条已匹配资料答案。补选后 22 道题均有有效当前答案；审核仍为待审，S4 查重过期数仍为 0。未改动答案文本或批次识别检查点。

## 验证

- S3 同文件、分文件、模型辅助配对及 S5 预检测试共 **68 项通过**。
- 前端生产构建通过。
