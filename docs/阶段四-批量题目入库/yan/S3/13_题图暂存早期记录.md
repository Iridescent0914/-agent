# S3：题图暂存早期记录

日期：2026-11-16。本文仅保留早期题图暂存的技术结论；当前流程以 [14_页段题答与题图一次识别](14_页段题答与题图一次识别.md) 为准。

## 保留的技术结论

- PyMuPDF 可按 PDF 位图的实际出现位置生成独立 PNG；DOCX 使用 S2 已校验的转换 PDF。
- 临时图片记录题目文件 ID、页码、归一化位置、PNG SHA-256 和尺寸。批次图片使用私有 API 返回，不暴露静态 URL；与原文件一同按 72 小时规则清理。
- PDF 渲染设置像素上限，单批题图设置数量上限。普通候选题修改接口不能直接伪造 `asset_ids`。
- 题答题图同次模型调用、自动定位、逐题图片上传与删除的当前行为见文档 14。
