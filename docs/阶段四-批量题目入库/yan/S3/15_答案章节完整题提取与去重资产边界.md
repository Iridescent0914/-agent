# 答案章节完整题提取与去重资产边界

日期：2026-11-16。适用于本次修改后新建的题答同文件批次。

## 问题与决定

`L7基础篇1-10讲习题解析.pdf` 一开始就有“参考答案与试题解析”。此前 S2 将标题后的页面视为答案区：整页可能跳过模型调用，即使模型返回完整题目，也会按页角色丢弃。这会使第一页提取 0 题，后续数量异常。章节标题只能提示内容来源，不能决定是否切题。

新批次采用联合提取提示词 v8：每个 PDF 页段都交给模型；只要题目完整且可独立使用，无论位于题目章节还是答案解析章节，都提取为候选题。答案另存为 `source_answers`。解析步骤、残缺题干、目录、知识讲解不构成候选。答案章节若完整重述前面的题，先保留两个候选，最后由整批去重判断；若文件从解析开始，没有前面的同题，保留该题。

## 去重与题图

整批去重只选择保留和移除的候选，优先保留前面的原题；不再因为某候选带答案就优先保留它，也不把被移除候选的 `answers` 或 `content.asset_ids` 复制到保留题。移除候选的完整 payload 仍保存在 `s3.model_removed_duplicates` 审计记录中。去重完成后，来源答案由 S2 独立提取的 `source_answers` 重新、保守地关联；冲突或归属不明的答案留待认领。

被移除候选曾关联的图片继续保留在批次暂存中。若图片 SHA-256 与保留题已关联图片相同，视为可确认的重复图，不放入普通未匹配图片列表；其审计来源仍可通过接口看到。其他图片不自动转移，显示在默认折叠的“无法匹配到题目的图片”中，并提示来自已去重题目；对应的保留题也显示核对提示。教师仍可在每题上传图片或删除已配图片。图片哈希不相同只能说明尚未确认相同，不能直接断言缺图。
