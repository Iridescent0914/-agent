# 模型判断题答区域与非独立题

## 原因

[05 题答混排页边界保护](./05_题答混排页边界保护.md)仍依赖预设标题。没有标题、标题写法不在规则里，或者同页混有题目和答案时，整页标签无法可靠判断每个段落。S2 过去还会跳过被规则认定为“纯参考资料”的页段；S3 曾按页删除旧候选，这会漏掉真题。

## 当前实现

- 新建的题答同文件批次使用 `question-import-combined-v4`。在 S2 原有的**同一次模型调用**中，模型结合前后题号、解题措辞、题干重述、答案位置和页内上下文逐段判断，不需要再为 S3 调用一次模型。
- `questions` 收独立题和模型无法确定的题。每题必须带 `source_classification` 与可核对的 `classification_evidence`；不确定题保留为候选并提示教师核对。
- 模型明确判断为答案区题干重述或讲解例子的内容，记入 `nonquestion_fragments`，包含原题号、原页码、简短摘录、类别和判断依据。S2 将它们写入页段检查点，前端可查看；这些片段不自动生成正式候选。原始模型响应仍按 S2 原有方式保存。
- v4 不调用 `pdf_page_roles`，不按固定标题或整页类别跳过模型、过滤题目或过滤资料答案。S3 对新旧批次均停止按整页类型删除候选；旧批次原有已完成的 S3 结果与已发生的移除保持历史状态，不自动重跑或恢复。
- v1～v3 进行中的批次继续使用各自原有输出契约，避免中途切换结构导致检查点与已付费结果不兼容。

## 限制与验证

模型仍可能漏读或误判。教师需查看模型列出的非独立题片段和不确定候选，并对照原文件确认；这些分类不是最终教师决定。当前只用模拟模型响应验证结构、存储和界面链路，**尚未用真实无标题或陌生标题文件验证模型判断质量**。真实样本验收前不能声称该场景识别准确。

后端测试覆盖无页角色调用、参考资料外观页仍发送模型、模糊题保留、非独立题证据记录、S3 不再整页删候选；S2/S3 定向测试 31 项通过，后端全量测试 294 项通过。前端 `npm run build` 通过。
