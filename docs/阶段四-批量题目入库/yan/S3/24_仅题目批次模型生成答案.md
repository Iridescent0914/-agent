# S3：仅题目批次模型生成答案

日期：2026-11-19。

## 范围与入口

- 仅 `questions_only`（只有题目文件）批次可调用模型生成答案；题答同文件、题答分文件批次由服务端拒绝。整批去重完成后，教师可选择为所有尚无答案的候选题生成，或只为某一道无答案题生成。教师也可直接手填答案。
- 已有资料答案或教师答案、已拒绝或删除的候选题、模拟候选题都不交给生成任务。任务排队和运行时禁止编辑候选题或同时启动标签建议；生成结果应用前再次核验候选题版本和题目内容，防止覆盖教师期间的修改。
- 启动需显式填写操作口令和本任务预算阈值。任务按最多 8 题、24,000 字符、8 张题图分组，只发送已提取的题干、选项、小题结构及已关联题图，不发送原 PDF。分组结果和模型用量、估算费用、响应 ID 存在批次检查点；完成组不重复调用。预算不足或调用失败后由教师显式续跑；用量未知时暂停自动重试并提示核对账单。单次调用仍可能超过阈值。

## 答案状态

- 模型逐题返回最终答案，或明确表示无法确定并说明原因。无法确定时不创建答案版本，题目继续保持无答案，教师可手填。
- 2026-11-19 将答案生成提示词升为 `s3-answer-generation-v2`：要求以题干、选项和实际题图为准，按原文核对数学符号、每个选项及其编号；仅在确实无法唯一确定时返回无法确定，并引用收到的原文说明原因。此调整针对模型将明确的 `1.2×10^8` 误读为 `1.2×108` 等情况，不改变教师核对要求。
- 有效结果新增 `model_generated` 答案版本，记录模型、提示词版本、响应 ID、题目内容指纹和生成时间；答案设为当前采用版本，但 `teacher_confirmed=false`，候选题决定仍为 `pending`，预审状态保持 `not_run`。模型答案不触发二次大模型预审，也不自动入库或入池。
- 教师编辑答案时继续新增独立的 `teacher_entered` 版本，不覆盖模型答案。通用候选题 PATCH 不再接受客户端直接替换答案版本或提示信息，避免伪造模型答案的教师确认状态。

## 验证与边界

- 定向测试覆盖场景限制、指定题目生成、已有教师答案保护、任务期间禁止编辑、严格逐题响应、无法确定时不猜答案，以及模型答案保持未确认。阶段四相关后端回归 76 项通过，前端生产构建通过。本轮没有发起付费模型调用；生成答案的数学正确率仍需用真实资料由教师核验。
- S5/S6 教师确认、正式入库与自动组卷池门槛仍按阶段计划后续实现；当前页面只提供暂存答案和教师修订入口。
