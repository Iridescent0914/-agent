# 未匹配题图人工关联

日期：2026-11-16。

## 需求

自动提取或自动裁剪的图片若未能对应题目，仍放在候选题上方默认折叠的“无法匹配到题目的图片”区域。教师查看后若确认归属，应能直接选定候选题并关联，无需重新上传同一图片，也无需手工裁剪。

## 实现

- 每张未匹配图片提供可搜索的候选题选择框，显示题目序号、原题号、来源页和题干摘要；选定后点击“关联到题目”。成功后复用原图片资产，刷新候选题和图片清单，图片直接显示在对应题目下，并从未匹配区域消失。
- 复用现有图片关联接口和候选题版本校验。服务端仍要求图片与候选题属于同一批次的同一题目文件；教师确认归属时，允许把答案章节后页重印的图片关联到前页原题，不再要求图片页码落在题目的原页段内。上传图片仍只能用于上传时指定的候选题。
- 自动识别的题图定位与来源校验不受此人工关联入口影响。

## 验证

- 后端容器中题图和复核相关测试共 20 项通过；其中新增测试覆盖同文件第 2 页未匹配图片关联到第 1 页候选题、关联后图片清单的题目 ID，以及跨文件关联被拒绝。
- 前端容器中 `npm run build` 通过，验证题目选择与关联控件。
