# S3：来源答案模型辅助配对指导

日期：2026-11-18。本文是本轮实现的指导约束，承接[分文件答案识别与保守关联](12_分文件答案识别与保守关联.md)。

## 目标与触发

- 先完成题目整批去重，再运行现有程序关联。题答同文件在去重完成后、题答分文件在答案文件全部识别后，自动进入模型辅助配对。只有题目的批次不进入此流程。
- 新批次自动配对使用启动 S2（同文件）或启动分文件答案识别时确认的预算剩额。旧批次不得因部署而自动产生模型费用；旧批次、预算不足或失败后重试，通过独立按钮确认预算和操作口令再启动。
- 模型任务只使用已提取的题目、答案、题号、来源页和本地可识别的章节信息；不重新发送原 PDF 页、页图或整份源文件。模型输出只能引用候选 ID 或表示无法确定，不能改写题干和答案。

## 配对策略

1. 先对来源答案做保守重复检查：同文件、同来源页、同题号与小题号、同题干摘录、同答案文本的重复转录只参与一次关联；原始提取记录保留。已关联到同题同小题的相同答案继续合并，不同答案保留为冲突。不得只凭答案文本相同跨题、跨讲次去重。
2. 程序先保留现有唯一题号、章节和原文题干摘录匹配。模型检查未匹配答案，以及题号重复且缺少唯一可靠消歧证据或存在证据冲突的已关联答案。若明确章节与题号唯一对应，或题干摘录唯一对应，且另一项证据不冲突，就不因重号进入模型核查。明确的跨页重复、教师已编辑的题目与答案不交给模型改动。
3. 按原题号分组发送提取文本，限制每组文本量与调用次数。每条输出包含来源答案稳定 ID、候选题 ID 或 null、引用原文的依据及判断结果。未匹配答案得到明确的候选 ID 和可在输入文字中核验的原文依据时，程序采纳模型配对；返回 null、证据无效、目标已有不同来源答案、与教师编辑冲突或同一位置出现不同答案时，保留在“待教师核对的问题”。
4. 对已关联的高风险答案，模型明确提出另一候选且有可核验依据时，不自动移动原关联，而是在“待教师核对的问题”中醒目展示原候选、建议候选和理由。模型返回 null 时归为“模型无法确定”，与明确异议分开显示。模型新配对仍是 `source_extracted`、`teacher_confirmed=false`，不得成为正式答案。不恢复按问题发送原页复核。

## 任务、费用和恢复

- 模型配对状态单独写入 S3 检查点，记录模型/契约版本、组进度、调用次数、用量、估算费用和错误。已完成组不得在重试时再次付费调用。
- 每组调用前检查剩余额度；一次调用可能超过预算阈值。用量缺失或请求结果不明时暂停自动重试，提示先核对账单。失败后只有显式续跑才可再次付费。
- 任务结束后更新来源答案关联统计和“待教师核对的问题”。答案仍无法判断时应明确保留，教师可以继续人工核对。

## 验收

- 测试新同文件与分文件自动触发、旧批次不自动付费、预算不足、模型拒答/无效 ID、教师编辑保护、小题冲突、幂等续跑、问题清单及 UI 状态。
- 用真实资料人工核对错误关联数、正确关联数、拒答数、调用费用与教师核对量；模拟响应测试不代表真实模型准确率。

## 本轮实现记录

- `question_import_s3_answer_match.py` 实现文字模型请求、结构化响应校验、分组、自动任务和显式续跑。单组最多 10 条答案、80 道候选，输入超过 35,000 字符的组保持人工待核对；按原题号聚合，缺题号时使用全批候选，题干摘录可补充跨题号候选。模型只得到题目及答案的已提取文本、来源页和本地页首短标题。
- 自动任务使用同文件 S2 或分文件答案识别的已确认预算剩额；旧批次没有自动标记。模型任务的剩余额度单独记账；状态、组进度、调用次数、用量、模型与计价快照及响应 ID 存于检查点，原响应存于私有批次目录。预算不足、响应无效或用量未知时暂停；无效响应须由操作员显式续跑，完成组不重新调用。
- 本轮进一步增加同来源位置答案重复检查；重号且有唯一、无冲突的题干摘录或明确章节证据时，跳过高风险模型核查。未关联答案只要模型明确给出有效候选 ID 与可核验原文依据、目标题没有已有答案且未被教师改动，就采纳关联；其余保留教师核对。
- 已关联答案的模型明确异议单列“模型建议更换已关联题目”，显示当前候选、建议候选、引用原文与理由；模型无法确定时单列“已关联答案模型无法确定”，现有关联不自动移动。
- 本轮针对性 S3 测试 **54 通过**、Docker 后端全量回归 **480 通过**，前端生产构建通过。尚未用真实百炼调用验证模型配对准确率与账单。
