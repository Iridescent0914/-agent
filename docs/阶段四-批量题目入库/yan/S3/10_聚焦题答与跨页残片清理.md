# 聚焦题答与跨页残片清理

> 历史开发记录：本文的同文件 v6 提示词及 v5 兼容说明已不适用；当前版本见 [提示词版本与历史兼容清理](../S2/14_提示词版本与历史兼容清理.md)。

日期：2026-11-15。根据教师反馈，后续新建的题答同文件批次将识别重点收敛到题目和资料答案。

## 新批次规则

1. S2 使用 `question-import-combined-v6`。模型只返回主体页开始的独立题目和原文标准答案；目录、示范解法、活动说明、答题卡、知识讲解及答案区重述题干不再作为非题目片段输出或保存。响应契约拒绝 `nonquestion_fragments` 字段。无法确认是否独立、但可完整转录的题目仍作为候选保留，供后续整批判重和审核。
2. 页段尾部的重叠页只用于补全主体页已开始的题目或答案。下一页段读取到上一题残留的孤立 `A.`、`B.` 等选项时，不再保存为未确定片段或“建议归属”记录。模型仍须报告主体页开始却无法完整辨认的题目或标准答案；这类问题不能因清理选项残片而被忽略。
3. 已经启动的 v5 及更早批次继续使用原来的输出契约和已有检查点；旧批次记录的非题目片段仍可查看或恢复。本次不重跑、删除或改写历史批次。

S3 整批模型去重与答案重关联仍按 [09 整批模型去重与题答重关联](09_整批模型去重与题答重关联.md) 执行。S4 正式题库查重、S5/S6 审核提交仍待开发。

## 验证范围

新增单元测试覆盖 v6 只接受题目和答案输出、旧 v5 契约继续可用，以及孤立选项片段不进入新页段检查点。真实资料的漏题、跨页补全和答案质量仍需后续抽查。
