# S2 无定界符 LaTeX 公式展示修复

## 问题

候选题中仍有 `求 \frac{a}{|a|}+\frac{b}{|b|}+\frac{c}{|c|}+\frac{abc}{|abc|} 的值` 等原样显示的 LaTeX。此前的公式渲染只识别 `$...$`、`\(...\)` 等显式定界符；模型在此题中直接输出了 `\frac` 命令。已保存的旧模型响应还存在双反斜杠写法。

## 调整

- 导入候选题显示时，传入模型提供的 `math_fragments`，优先用它定位题干与选项中的原始公式片段。
- 对没有定界符但含常见 LaTeX 数学命令的连续片段做显示层识别，兼容缺少或未对齐的 `math_fragments`。
- 传给数学渲染组件前，将模型输出的双反斜杠命令归一化为单反斜杠。原始候选题数据与模型响应不改动。
- 识别只在导入候选题界面启用；其他题目页面仍按原有定界符规则显示。

## 验证

用单反斜杠和双反斜杠的分式示例验证均可匹配为一个完整公式片段；前端 `npm run build` 通过。此修复不需要再次调用百炼，不增加模型费用。界面显示改善不代表公式内容已经和原文件核对，教师仍需在后续复核中确认。
