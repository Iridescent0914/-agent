# S2：Flash 默认模型与区域坐标取舍

日期：2026-11-13。

## 决策与依据

S2 默认模型由 `qwen3.8-max` 调整为 `qwen3.8-flash`，同时把北京地域试算单价改为输入 0.8 元/百万 Token、输出 2.7 元/百万 Token、PDF 解析 0.02 元/页。已完成的 Max 批次保留原模型和价格快照；尚未启动的批次使用新配置。用户本地 `.env`、示例配置、Compose 缺省值和后端缺省值同步调整。

依据是[两页同页对照](./03_Flash与Max同页对照试验.md)：两模型均切出 8 道题，Flash 的估算费用为 0.057214 元，Max 为 0.500572 元；Flash 总耗时 68.295 秒，Max 为 224.161 秒。两页样本中题数、选项、子题和数轴文字线索接近，但不能据此认定跨页、扫描件或复杂几何图同样可靠。后续仍需扩大人工核对样本，并和控制台实际账单比对。价格依据：[Flash 模型价格](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)、[PDF 理解计费](https://help.aliyun.com/zh/model-studio/pdf-understanding)。

## 区域坐标

S2 的核心结果是候选题内容与来源页码。模型建议坐标未经视觉验证，且在现有 Flash 样本中缺失。后续决定取消该字段：S2 不请求、不保存新坐标；历史试验响应作为原始记录保留。详见[后续变更](./06_仅Flash与取消模型区域坐标.md)。

S3 仍要解决含图题目的图像资产和题图归属。做法是从原页出发，必要时用程序定位或教师手动裁剪，并保存可核对的原页证据。仅存模型对图的文字描述不能代替题图。

## 子题字段变化的原因

S2 提示词要求输出子题，却没有把每个子题限定为唯一 JSON 形状。百炼的 JSON Object 模式保证 JSON 语法，不保证子字段名固定；不同模型或不同调用可能把相同的“子题编号＋文字”写成字符串、`key/text`、`number/text` 或 `label/text`。本次 Flash 样本 A 使用了 `label/text`，并非百炼 API 更改，也不是题目内容改变。后端现对已观察到的四种形式逐一严格校验，统一映射为候选题中的带编号文本；其他未知结构仍拒绝。原始付费响应在校验前已私有保存，因此修复后可复用响应，不必再次调用模型。[结构化输出文档](https://help.aliyun.com/zh/model-studio/qwen-structured-output)说明 JSON Object 与 JSON Schema 的保证范围。

## 验证范围

当次切换仅改变后续调用的默认模型和费用估算参数，没有重新发起付费模型调用，也没有改变已完成批次的候选题。切换前的批次状态为 1 个 `awaiting_s2`、2 个 `s2_completed`，没有正在执行或等待恢复的 S2 页段。重建后端后，容器读取到 `qwen3.8-flash`、输入 0.8、输出 2.7、PDF 每页 0.02 的配置；当次 S2 定向测试 **8 passed**，后端全量测试 **271 passed**。后续已限制 S2 仅允许 Flash。
