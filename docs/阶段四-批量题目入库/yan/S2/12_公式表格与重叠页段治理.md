## 问题与处理

- 候选题预览此前仅识别显式 LaTex。现对裸写的幂、斜线分数及带分数补充数学式识别；`1/2` 显示为竖式分数，`1 3/4` 显示为带分数。已有 `$...$` 和 `\(...\)` 仍按原路径渲染。
- 模型输出的 Markdown 管道表格现在转换为真正的 HTML 表格，表格单元格同样支持公式显示。已用“第一袋～第四袋”真实候选题在页面中核对。
- 候选题先按原精确键判重，再按来源文件、原页、原题号、正文和选项判断格式变体。同页同题号是强身份线索，仍须核对选项及数字：`±7` 与 `\pm 7`、`×` 与 `\times`、`0°C` 与 `0^{\circ}C` 视为相同；数字或选项内容明显不同时保留供人工核对。无选项的题还可识别一份仅含部分小题、另一份含完整小题的情况。去重信息写入页段检查点；新提取的版本更完整时保留完整版本。
- 后一页段把共享页开头的选项报为“未确定”时，若上一页段中跨页题已包含同一选项，记为 `resolved_overlap_fragments`，不再向教师显示误报。其他未确定片段仍保留。
