# S5-A：审核规则与只读预检实现记录

日期：2026-11-22。状态：服务端 S5-A 已实现；教师确认与审核日志已在 [S5-B](03_逐题审核与问题处理实现记录.md) 落地，工作台界面和正式提交仍待后续阶段。

## 已实现

- 新增 `POST /api/v1/question-imports/{batch_id}/s5/preflight`。请求显式列出候选题 ID、预期版本、拟采用的 `library_only` 或 `direct_pool` 路径；直接入池可携带逐小题/空的结构化答案**草稿**。接口只读取批次、候选题、标签目录、题图、S4 最新检查和答案草稿，不保存审核决定、不创建正式题、不调用大模型。
- 响应按题返回 `blockers`、`warnings`、`batch_eligible`、当前版本和路径，并汇总选中、可确认、阻断及两条路径数量。这里的 `batch_eligible` 仅表示**当前具备进行教师确认动作的客观条件**，不表示教师已确认，更不是 S6 可直接提交。响应固定包含 `confirmation_pending=true`；S5-B 将负责保存可信的教师审核事件。
- 新增 `GET /api/v1/question-imports/{batch_id}/s5/summary`，汇总真实/测试候选数、当前候选决定、可进行仅题目确认的数量、仍需答案结构化审核的数量、缺失/过期的查重检查、精确/相近命中、未认领答案及图片等。直接入池的“可确认”计数基于当前已保存的数据；未随汇总请求传入结构化答案草稿的题会显示需要答案审核。
- 预检校验批次和冻结标签目录、非 fake/未删除候选、预期版本、题干和选项、正式题型、难度、必做标记、主属 KP 在正式开放目录及数据库中存在，以及年级/章/节/完整核心素养与主属 KP 的派生结果一致。
- 题图缺失、过期、非本批来源会阻断；已关联但提取状态不确定会提醒教师核对。S4 未检查、结果过期、检查版本旧、精确命中、相近题待决定、已有跳过决定或正式题题图无法可靠比对都会给出逐题原因。低于当前 S4 文字门槛的新近邻不会产生待决定阻断；这不证明题库不存在同题。
- `library_only` 允许无答案并提示后续审核。`direct_pool` 只接受当前自动组卷池支持的选择、填空、判断题，要求选定有内容的答案版本、可靠的题答关联和结构化答案草稿。将现有正式答案审核中的纯校验抽为 `prepare_pool_review`，预检和正式晋级共用题型、答案项、自动判分与标准答案自判分规则。模型答案文本或所选答案 ID 不构成确认；教师确认仍由 S5-B 完成。

## 请求示例

```json
{
  "items": [
    {"item_id": "候选题 UUID", "expected_revision": 1, "route": "library_only"},
    {"item_id": "另一候选题 UUID", "expected_revision": 2, "route": "direct_pool",
     "answer_review_items": [
       {"item_id": "answer-1", "subquestion_no": 1, "blank_no": 1,
        "answer": "A", "answer_match_type": "choice"}
     ]}
  ]
}
```

响应中的阻断是逐题返回，不会静默把 `direct_pool` 降为 `library_only`。请求只允许本批次候选题；重复选择同一候选题在请求校验时拒绝。查看或预检不改变候选版本和 S4 检查记录。
