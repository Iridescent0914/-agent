# S5-D：批量审核与联调实现记录

日期：2026-11-24。

## 完成内容

- 工作台新增“批量预检与审核”。教师可手选题目、选择全部待审题，或先按所选入库路径预检并仅选通过的题。每次最多 200 题。
- 所选题逐题展示题干、选项、题图、标签、来源答案、原题号和 S4 查重状态；预检逐题显示阻断与提醒，并汇总通过和阻断数量。自动筛选时，未通过的题在选择列表保留阻断原因。未选题仍留在待审范围，不随批量操作改变。
- 提供“仅题目入库”和“题目与答案直接入池”两种审核意向。直接入池时，每道题分别填写结构化答案项，可填写小题号、空号、标准答案、可接受答案和判分方式。
- 服务端 `POST /api/v1/question-imports/{batch_id}/s5/items/bulk-decision` 在锁定批次与候选题后，先独立校验每道题的版本、状态和 S5 预检规则。任一题阻断，返回 HTTP 409 及逐题阻断原因，整组不写审核记录。全部通过后在一个事务内逐题记录审核；直接入池另写每题答案审核事件。事件以同一个 `batch_action_id` 关联此次教师操作。
- 批量拒绝仅对明确选中的待审候选生效，要求填写共同理由；每道题各有独立题目审核事件。刷新后继续通过现有 S5 审核查询恢复状态。

- 浏览器只读联调：在一个现有 22 道待审题批次中，按“只选当前预检通过的题”选出 18 道；再次预检显示 18 道通过、0 道阻断，确认按钮正确启用；切换直接入池路径后逐题答案草稿正常显示。未向真实批次写入审核决定。

## 交给 S6 的输入

批量操作只保存审核意向，**没有创建正式题目或晋级组卷池**。S6 应读取候选题 ID 与最新版本、有效的题目审核事件、直接入池时的答案审核事件、S4 决定引用及入库意向；正式提交时重新执行题目与答案校验、查重和并发保护。

S4 小规模人工标注评测与向量检索按既定决定暂缓，不影响 S5-D 的审核规则；真实试运行前仍需完成评测。

三种文件方式的验证使用受控测试批次及 S5 API，未重新调用识别模型完成真实文件上传到 S5 的全链路。后续真实试运行仍需用教师提供的样本逐步核对识别结果。

## 2026-11-26：单道选择题答案编号防误填

单道选择题只有一个答案项时，小题号和空号应留空，由答案结构默认映射为第 1 小题第 1 空。此前教师填写任意 1～99 的编号仍可能通过预检，进而影响答题卡上的作答位置。S5 现对这类草稿禁用编号输入；服务端预检也拒绝带显式编号的单答案项选择题。若教师先添加多个答案项、再删回一个，已有编号仍可在界面清空。多个小题或空的答案目前仍须教师按实际题目结构逐项添加和核对，系统没有从整段来源答案中可靠自动拆分的能力。

## 2026-11-27：多小题与多空题直接入池门槛

多个答案项拟直接入池时，每项必须显式填写小题号和空号；缺任一编号会阻断 S5 预检和单题、批量确认。题干可识别多个小题或空位时，答案项数量及坐标还须与识别结果一致；来源答案带多个顺序编号时，也不能只交一个选择题答案项。题干未提供可识别的多个位置时，所填编号也必须从 1 开始连续。仅题目入库不受答案编号影响。页面明确提示：编号或答案尚未核对好时选择“仅题目入库”，后续在正式题目的答案审核中补齐并晋级；不得把“仅题目入库”称为“仅题目入池”。结构识别只覆盖常见的 `(1)(2)` 编号和连续下划线空位，未识别的复杂版式仍需教师核对。

## 2026-11-27：选择题判分方式说明

2026/11/24 15:43:25 的 22 道题全部标为选择题，每题实际选项为 A～D。此前逐题弹窗把选择题唯一可用的判分方式写为“选项 A-H”，容易误解为本题有 A～H 选项；批量弹窗还显示数字、文字和公式方式，但服务端会拒绝选择题使用这些方式。现统一显示“选项字母”，并在逐题和批量审核中列出本题实际有效选项。S5 直接入池预检还会验证标准答案及可接受答案都属于该题的实际选项；若题型被误标为选择题，须先修正候选题标签。

## 2026-11-27：批量自动筛选复用预检结果

“只选当前预检通过的题”本身已经调用 S5 预检。此前界面只把通过项加入勾选列表，却丢弃这些题的预检结果，导致教师必须再次点击“预检所选题目”才能确认，造成重复请求。现在自动筛选会保留通过项的预检结果，教师核对后即可确认；手动改动勾选范围、路径或答案草稿仍使结果失效，需重新预检。正式保存时服务端仍会在事务内重新校验每道题。

## 2026-11-27：题图误阻断与相近题人工判断修正

- 2026/11/24 15:43:38 批次第 5 题已把四袋食品的表格数值完整写入题干，但模型仍留下“表格”题图线索，导致预检误报关键题图缺失。候选题现提供“确认文字已完整表达，无需题图”和撤销操作；教师须对照原文件确认。确认记录包含时间与题干、选项、题图线索的签名；内容变化后确认失效，修改题干时主动清除。此操作只消除缺图阻断，不代替答案和标签审核。
- 相近正式题的内容无法自动核验时，页面仍提供人工判断按钮；教师可核对旧题并选择跳过、独立变式或无关，判断理由选填。服务端保存旧题内容快照签名，旧题变化后原判断失效；待判断仍阻断预检，教师作出明确判断后不再以“无法自动核验”阻断。提示改为“正式题内容无法自动核验，请人工核对”，不再一律称为图片问题。

## 2026-11-28：重复查重后拟入库题消失修复

- S5 审核签名原先包含 S4 每次重查都会重新生成的检查 ID 和匹配记录 ID。教师已确认后再次点击“检查题库重复”，即使题目及查重证据未变，审核记录也被判失效，“拟入库清单”随之消失。
- 新审核记录改用题目内容、答案、标签及稳定的查重证据计算签名；旧审核记录保持追加式审计不改写，通过原检查记录与最新检查记录的证据一致性兼容读取。同样证据的重查保留确认；新相近题、查重决定或正式题内容发生实质变化时仍需重新审核。
- S4/S5 定向测试 41 项通过，覆盖新旧审核记录的相同证据重查及新增近邻失效。本地 2026/11/24 15:43:25 批次在第 8 次查重后仍有 22 道有效的已确认题，旧审核失效数为 0；未重新写入教师决定。
- 批量审核的确认按题独立生效。仅证据变化的题进入“旧审核已失效”，其余题保持已确认并留在拟入库清单；失效题在查重问题处理完后可重新进入批量审核列表。修复了页面按旧 `teacher_decision` 排除失效题，以及批量接口拒绝重新确认失效题的问题。
- 新增两题批量审核后仅一题查重证据变化、重新批量确认的回归测试。S4/S5 定向测试现为 42 项通过，前端 `npm run typecheck` 通过。

## 2026-11-28：一键撤销全部拟入库审核

- “拟入库清单”提供“一键撤销全部拟入库”。当前清单中的有效确认全部撤回，包括批量确认后又逐题重新审核的题，以及原本逐题确认的题。确认弹窗显示题数；撤回后题目回到待审，历史审核记录保留。
- 撤销接口 `POST /api/v1/question-imports/{batch_id}/s5/items/bulk-revoke` 接收清单内所有题目 ID 与版本。服务端锁定批次及所选题，并核对请求恰好覆盖当前所有有效拟入库题；遗漏、状态变化或版本冲突时整次拒绝且不写入。通过后在一个事务内逐题追加待审事件，记录对应的原审核事件 ID。
- 撤销只改变 S5 审核意向，不删除候选题，也不修改题库；S6 正式入库仍待实现。
- 定向测试覆盖重新逐题审核后仍被全部撤销、部分或过期请求零写入。S4/S5 测试 44 项通过，前端 `npm run typecheck` 通过。
