# S4：查重证据与教师决定持久化实现记录

日期：2026-11-20。状态：查重记录和决定已实现；正式入库事务的最终复查与并发保护待 S6 接入。

> 2026-11-21 题图展示调整：不再计算或返回视觉特征距离；旧检查记录中的该字段也不再对外展示。题干文字相同、题图文件不同的相近题直接提示人工核对，并可从导入页打开正式题详情查看题图。文件不同不等于视觉内容必然不同。

## 实现

- 迁移 `0040` 新增 `question_import_catalog_checks` 和 `question_import_catalog_matches`。每次执行“检查题库重复”都保存各有效候选题的检查序号、内容签名、规则版本、命中的正式题、差异证据和检查时间；旧检查保留供追溯。
- `POST /question-imports/{batch_id}/s4/review` 执行精确匹配和索引近邻召回并保存新检查。`GET /question-imports/{batch_id}/s4/review` 查询每题最新检查。近邻相似度仍只是排序线索，没有经过人工样本校准，不能自动决定是否重复。
- `POST /question-imports/{batch_id}/s4/items/{item_id}/matches/{match_id}/decision` 使用候选题预期版本保存决定。精确命中只能选择跳过旧题或待决定；近邻可选择跳过、确认独立变式、判为无关或待决定。独立变式及跳过近邻须填写理由。跳过会标记候选题为 `skipped_duplicate`，并记录关联的正式题；不会改写正式题及其答案、图片。
- 候选题题干、选项或题图变化会使旧检查过期；正式题归档或内容变化会使对应匹配过期。重新检查只在候选内容签名、正式题内容签名与匹配类别均未变时继承原决定，否则复位。标签和答案变化不改变题目内容签名；展示时根据当前选中答案重新计算与题库答案的文本冲突提示。
- 通用候选题编辑接口不能直接写入 `skipped_duplicate`，也不能绕过查重记录清除已有跳过决定。页面展示保存的证据、过期状态、理由输入及撤销决定入口。

## 验证

- 本地开发数据库已升级至 `0040`。后端 S4 定向测试覆盖精确跳过、重复检查继承、内容变化失效、近邻理由、正式题修改、答案变化，以及通用接口绕过拦截。
- 前端构建通过。真实题库召回质量和阈值仍需人工标注样本验收。

## 后续边界

目前没有 S6 正式入库接口，页面不会把候选题写入正式题库。S6 必须在建题事务内重新查正式题库，检查最新候选版本与教师决定，并以指纹锁或等价机制串行化所有正式建题入口；否则本次保存的检查结果不能防止检查后新增的重复题或两个批次并发建题。现阶段 `decision_scope` 为内部演示范围，尚无可信的逐教师身份审计。
