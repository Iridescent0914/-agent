# S4 第一阶段：候选题与正式题库精确查重

日期：2026-11-20。状态：已实现并通过本地验证；S4 整体尚未完成。

## 本次实现

- 新增固定版本 `s4-exact-v2` 的数学题内容指纹。规范化可信的题号前缀、空白、全半角及常见负号；上标、下标转成显式指数/下标。只转换明确的字符，不对全文使用 NFKC，以保留圈号等可能有数学含义的字符。题干、选项键值及顺序、关联图片的实际文件 SHA-256 一同参与计算。答案和标签不参与题目指纹。旧 `content_fingerprint` 保留，避免与旧规则混用。
- 迁移 `0034` 为正式题添加带索引的 `exact_fingerprint_v2`，对历史题回填。正式题编辑、种子题导入同步更新新指纹。图片或内容无法可靠读取的正式题保持空值，不伪造可比较的指纹。
- 新增只读接口 `GET /api/v1/question-imports/{batch_id}/s4/exact-matches`。仅在 S3 整批去重完成后，检查本批未删除的真实候选题。用指纹索引一次查询正式题，返回全部历史精确命中，并再次对比实时规范化内容；结果带候选 `revision`、正式题 `review_revision`、未索引正式题数量和答案文本差异提示。不修改候选、正式题或 S3 批内去重状态。
- 候选题页面新增“检查题库精确重复”按钮和逐题结果展示。候选内容改变后，旧查询结果按 revision 标记过期；重新点击可获取最新结果。界面明确区分“未检出精确重复”和“无法可靠比对”。

## 已验证

- 自动化验证覆盖 `10⁸` 与 `10^8` 等价、`10⁸` 与 `108` 区分，字母上标、圈号、正负号、单位、选项顺序和选项数值、图片字节变化、缺图线索，以及题库同题多条记录和答案文本不同。
- 本地迁移后题库 180 道正式题中 177 道有新指纹，3 道因内容或题图不可可靠计算而未索引。对一批 S3 已完成的 22 道候选题进行只读试跑：精确命中 0 道、无法比对 0 道、未索引正式题 3 道。这个结果不是人工标注的召回率报告。
- `pytest -q tests/test_question_import_s4_exact.py tests/test_question_import_s3.py tests/test_question_review.py`：28 项通过。前端 `npm run build` 通过。

## 当前边界与下一步

- 图片采用原始文件字节哈希，格式转换、重新裁切或重编码后的同一视觉图片可能漏掉精确命中；此类题要由后续疑似题召回处理。缺图、图片线索未解决和无法读取的图片标为“无法可靠比对”。
- 页面展示的是点击时的只读查询结果，未保存教师决定，也不阻断入库；正式题在查询后发生变化时，需要重新检查。S5/S6 仍需实现结果持久化、教师审核、提交前复查与并发保护。
- 下一步收集人工标注的真重复、合法变式和含图题样本，实现有索引的疑似题召回与差异展示。当前“未检出精确重复”不表示题库确认无重复。
