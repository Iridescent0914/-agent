# 数轴图资源与循环小数答案显示修复

2026-11-11

## 问题与修复

- 题目 `q.math.g6.rational.school.010` 和 `.023` 的题干包含两个连续的 `[ASSET:unknown]`，前端因此显示“图片或公式资源加载失败”。原始 Word 的画布 49、83 仍保存完整数轴线条与文字坐标。`scripts/recover_rational_number_lines.py` 按这些坐标导出 SVG，来源和文件哈希见 `data/audit/rational_number_lines_provenance.json`。题干改为引用各自的 SVG，资源清单和网页资源目录已同步。
- `q.math.g6.rational.school.004` 的 `-1,-0.\overline{404}` 是 `-1,-404/999` 的备选正确写法。原页面把 LaTeX 命令直接当文字显示，且重复列出主答案。现在答案视图会渲染这类数学命令，只列出与主答案不同的备选写法；判分规则和答案数据未变。
- 图形修复使用 `asset_only` 校正模式，只允许替换缺失图的占位符、登记新图和清除资源关系缺失标记。两题仍是 `raw_answer_only`，尤其 `.023` 的参考答案仍待教师审核，没有进入自动组卷池。

## 核验

- 有理数章资源清单：566 个资源已转换，失败 0、未解析引用 0。
- 当前本地数据库共 180 题，逐题检查题干资源引用，未发现无法解析到网页 URL 的占位符；两张新增 SVG 的 HTTP 请求均返回 200。
- 本地数据库仅对 `.010`、`.023` 更新了 `question_text`、`assets`、`import_issues`；修复后预览无待更新项，学生作答与组卷等业务表校验值保持一致。
- 后端容器中 `tests/test_question_pool_governance.py`：28 个测试通过；前端 `npm run build` 通过。
