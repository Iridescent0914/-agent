# 移除上传单题功能

2026-11-07，根据当前需求移除题库中的单题上传/手动新增功能。

## 调整范围

- 题库页移除“上传新题”按钮、录题弹窗、图片选择及提交逻辑，同时移除仅用于新增题目的表单状态、知识点请求和样式。
- 后端移除 `POST /api/v1/questions`；请求该地址新增题目会返回405，OpenAPI也不再公布新增操作。
- 前后端请求模型统一为已有题目使用的 `QuestionUpdateRequest`，清理不再使用的创建请求类型。
- 题库继续由源文件及导入脚本维护。题库列表、筛选、详情、已有题目编辑、答案审核、入池/撤回和业务归档继续可用。
- 图片上传和资源清理接口由已有题目编辑复用，继续保留；学生答题照片上传不属于本次调整范围。

本次不需要数据库迁移，不删除已有题目、图片或历史业务数据。先前的开发记录保留当时状态，当前功能说明以README及本记录为准。

## 验证

后端增加接口退役检查，验证新增请求返回405、题目数量不变且OpenAPI无新增操作。原先依赖新增接口的编辑/审核/归档测试改为事务内准备已有题目，继续覆盖这些保留功能和图片引用保护。

前端增加桌面及手机浏览器检查：题库不再显示上传按钮，关键词筛选可进入原题，已有题目的编辑弹窗仍可打开和取消。

```powershell
docker compose exec -T backend pytest -q
docker compose exec -T frontend npm run build
# Windows主机frontend目录：
$env:PLAYWRIGHT_PORT='5175'
npm.cmd run test:e2e -- tests/question-catalog.spec.ts tests/question-answer-assets.spec.ts
```

后端完整测试219项通过，前端production build通过。桌面与手机题库操作测试2项通过，图片及答案显示回归6项通过。首次题库测试因Ant Design为双字按钮加入空格而未能定位“筛选”，修正定位规则后复跑通过，未改变产品交互。
