# 阶段五：自动组卷池与题目答案治理

## 阶段定位

本阶段集中处理自动组卷池中题目的数据质量、答案结构和入池安全问题，不再归入学生画像与个性化推荐阶段。

## 主要范围

- 选择题、填空题、判断题、计算题和简答题的答案结构统一；
- 复合题按“小题—空/作答区”拆分最小答案单元；
- 自动组卷池的入池、撤回、重新审核和版本审计；
- 机器判分就绪状态、缺失答案和歧义答案的校验；
- 已入库题目、种子数据和发布快照之间的数据边界；
- 组卷、答题、判分和人工复核对统一答案契约的兼容。

## 边界说明

本阶段处理的是题库与自动组卷池的题目、答案和审核状态。学生作答产生后的掌握度、素养分、知识点回顾状态等画像逻辑仍归阶段三维护。
