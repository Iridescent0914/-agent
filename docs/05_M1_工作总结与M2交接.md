## 3. 数据库与迁移

迁移链：

```text
0001 create knowledge and question tables
0002 create student and mastery tables
0003 create assignment, paper and attempt tables
0004 protect published paper snapshots
```

关键约束已经落库：

- 题目 `original_qid` 唯一；
- 知识点 / 考点源 code 唯一；
- 一题只有一个主考点；
- 同一作业、学生和版本号唯一；
- `instance_code` 全局唯一；
- 同一试卷题号唯一；
- 一份试卷只有一个逻辑 Submission；
- 一个 PaperInstanceItem 只有一个当前 Attempt；
- `needs_review` 时 `is_correct` 必须为空；
- published PaperInstance 及其 PaperInstanceItem 不可修改或删除。

`StudentMastery` 表已经建立，但 M1 不写入伪造 mastery；M2 从历史 Attempt 重放生成。

## 5. 后端 API

已实现：

```text

GET /api/v1/questions
GET /api/v1/questions/{question_id}
GET /api/v1/students
GET /api/v1/students/{student_id}
```
